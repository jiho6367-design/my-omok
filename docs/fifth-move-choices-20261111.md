# 5수에서 무적수·동등 자료 함께 선택 · v5.18.46

선공의 5수에서 **기존 무적수·정석 후보**와 **동등 자료 후보**를 함께 표시합니다. 기본 추천, ‘무적수 초반 정석’ 표시와 기존 후속 조회는 그대로 유지합니다. 동등 자료는 사용자가 원하는 수를 직접 고르는 추가 선택지입니다.

## 사용하는 방법

1. 기존처럼 3수를 두고 상대 4수를 입력합니다.
2. 판 아래의 두 그룹을 비교합니다. 기존 추천은 원래 추천 위치에 표시됩니다.
3. 원하는 그룹의 좌표 버튼이나 판 위 반투명 돌을 눌러 5수를 둡니다. 별도 모드 전환은 필요 없습니다.

같은 좌표가 두 그룹에 있으면 판에는 돌 하나를 표시하고, 그룹별 버튼과 자료 설명은 각각 유지합니다. 동등 자료가 없는 상대 4수에서도 기존 정석과 일반 분석은 계속 동작합니다. 기존 3수 선택과 7수 이후의 추천 방식은 유지합니다.

선택 기록은 실제 착수에 별도 메모로 저장합니다. 기존 엔진 추천·증명 기록은 덮어쓰지 않습니다. 동등 수를 선택한 뒤에는 실제로 둔 판에 맞는 기존 후속을 조회하고, 해당 판의 등록 후속이 없으면 일반 분석을 사용합니다.

## 동등 자료의 범위

현재 수동 선택 자료는 **281개**입니다. 기존 169개(2019년 소시르프 개국 안내서의 동등 140개·단서가 붙은 동등권 28개와 포월의 과거 평가 상충 참고 1개)를 모두 보존하고, 2026-04-03 《漱星阁开局指南》의 명시 동등 평가 112개를 추가했습니다. 합계는 단서 없는 동등 252개·동등권 28개·과거 평가 상충 참고 1개입니다. 양색 선공과 회전·반사 8가지를 지원하며, 상대 4수까지의 전체 돌 배치가 맞을 때만 표시합니다.

정규 26주형의 빈 상대 4수 222곳씩, 총 5,772개 판을 조회하면 후보 지원이 174곳에서 217곳으로 늘었습니다. 새 43곳 외에도 기존 63곳에서 5수 선택지가 증가합니다. 대칭을 합친 새 4돌 국면은 31개이며, 모든 상대 4수를 지원한다는 뜻은 아닙니다. [추가 자료의 출처·대표 수순·보류한 후보](more-balanced-fifths-20261111.md)에 범위를 정리했습니다.

평가는 `동등`, `후공 약우`, `복잡한 동등`, `선공 약우`로 구분합니다. 원자료의 흑·백은 각각 선공·후공 역할로 표시하므로 백돌 선공에서도 뜻이 유지됩니다. 이 자료의 ‘평형’에는 복잡해서 판단하기 어려운 형세도 포함됩니다. **우리 규칙의 동등 증명이 아니며 자동 추천의 우선순위를 바꾸지 않습니다.**

기존 안내서 출처는 喵声依旧의 [《索索夫规则 开局指南》, 2019-07-01](https://github.com/taotao568685/Renju-files/blob/master/%E7%B4%A2%E7%B4%A2%E5%A4%AB%E5%BC%80%E5%B1%80%E6%8C%87%E5%8D%972019-07-01-CHS.pdf)이며, 신규 출처는 [《漱星阁开局指南》, 2026-04-03 PDF](https://note.com/api/v2/attachments/download/e92da2a6017b61bfb3ef89437d0f6294)입니다. 자료별 원문 쪽수·대안 5수 번호를 보존합니다. 원문·이미지·긴 설명은 배포하지 않습니다.

## 포월은 과거 평가의 상충을 따로 표시

`H8 I9 I7 G9`에서 기존 무적수 기본 추천 **J8**은 유지합니다. 추가 수동 참고 후보 **F8**은 `과거 동등 · 평가 상충`으로 표시합니다.

- Yuriy Tarannikov의 [Dictionary of Yamaguchi rule](https://www.renju.net/forum/thread/305/), 2009-08-29 수정본의 board20은 이 F8을 동등으로 평가합니다.
- 2019 안내서 PDF 25쪽·책 19쪽에서는 같은 F8을 복잡한 후공 우세로 평가합니다. 도표 번호 6이 F8이고, 함께 표시된 번호 7은 K9입니다. 이 번호들은 5수 대안이며 이어지는 착수 번호가 아닙니다.

따라서 이 후보를 현재의 확정 동등 수로 부르지 않습니다. 자동 추천에는 사용하지 않으며, 평가가 엇갈린다는 설명과 함께 사용자가 직접 선택할 수 있는 참고로만 제공합니다. 사진처럼 반사·회전된 판에서도 기존 추천과 참고 후보를 각각 변환해 함께 표시합니다.

## 검증과 보존

- 기존 자동 추천 함수와 기본 정석 선택을 수정하거나 교체하지 않습니다.
- 같은 판에서 기존 추천과 두 그룹을 동시에 확인하고, 각 그룹을 눌러 실제 선택한 5수가 두어지는지 검사합니다.
- 양색·8대칭, 겹치는 좌표, 자료 없는 응수, 일시 정지와 오래된 버튼, 3·7수의 기존 선택을 검사합니다.
- 추가 자료의 모든 첫 5수 합법성과 현재 판 전체 일치를 확인합니다.
- 실제 사용자 실행 파일과 공개 빌드를 확인하며, 기존 모델·개인 외형·저장 키·기보·미완료 실험은 보존합니다.
