# v5.18.22 · 포월 174응수의 엔진 사전분석

기본 포월 `H8 I9 I7 G9 J8` 뒤 합법 상대 6수 220개 중 기존 공개 정석 자료가 없는 174개를 각각 직접 분석해 7수 대응을 추가했다. 원래 정석 추천 46개는 그대로 우선한다. 이 국면에서는 두 종류를 합쳐 220개 모든 상대 응수에 대응을 표시한다. 화월·다른 주형이나 다른 포월 5수의 전체 응수까지 확장했다는 의미는 아니다.

새 174개는 **엔진이 제한된 시간에 비교해 고른 대응 추천**이다. 책·영상 정석으로 표시하거나 전체 필승·무패의 증명으로 취급하지 않는다. 기존 출처 정석 31,975개와 별도 자료로 보관한다.

## 직접 계산과 검증

- 분석 기준은 공개 v5.18.21 소스 커밋 `2c62789c2a01af29e175ee48d5215f67e35085f8`과 당시 배포된 채택 모델이다. 미채택 엔진·학습 후보는 사용하지 않았다. 이번 변경은 새 모델 채택이 아니다.
- 174개 각 국면에서 심층 모드에 1초 예산과 별도의 15초 예산을 배정해 실행했다. 최종 대응은 15초 예산의 결과를 사용한다. 엔진이 후보 비교를 마치면 예산 전에 종료할 수 있으며, 지정 예산과 실제 소요 시간은 분리해 기록했다. 조사한 후보 범위의 비교 결과이며 모든 합법 후보의 최적성 증명은 아니다.
- 자동 기보 조회를 끄고 직접 수읽기를 실행했다. 원래 5수·상대 6수·추천 7수와 예상 수순의 합법성, 정확한 5목 종료, 즉시 승리와 필수 방어를 검사했다. 각 추천 뒤 상대의 다음 수를 별도 750ms 엔진 분석으로 다시 확인했다. 그 시간 내 반증이 없다는 사실을 안전·무패 증명으로 해석하지 않는다.
- 앱에는 대응 좌표·분석 예산·실제 시간·완료 깊이·노드 수·엔진 식별자·원결과 SHA-256을 넣는다. 전체 탐색 결과·반격 검사·시험 기록은 로컬에 보관한다. 게임 중 표시하는 현재 탐색 깊이·노드·증명 상태에 과거 계산량을 합산하지 않는다.
- 규칙은 양측 33 금지, 44 허용, 정확한 5목 우선이다. 6목 이상은 승리가 아니다. 같은 국면의 돌 색 교환과 8대칭에 모두 적용한다.

## 실제 앱 동작

자동·빠른 모드에서는 **기보 따라두기 체크 없이** 7수 대응을 바로 조회한다. 화면에는 `엔진 사전분석 대응 · 포월`을 표시한다. 강제승을 표시하지 않으며 이전 분석의 완료 깊이와 예산은 별도로 설명한다.

새 7수 뒤의 상대 착수는 다시 현재 판의 엔진으로 분석한다. 정확한 6돌 배치가 다르거나 종료된 판, 잘못된 선후공 역할, 금수·이미 점유된 추천은 조회하지 않는다. 즉시 승리·필수 차단과 확인된 반증은 저장된 대응보다 우선한다.

**심층 모드**는 새 174개 대응의 사전분석을 건너뛰고 현재 판을 새로 계산한다. 직접 설정 시간이 사전 예산 15초보다 길 때도 새로 계산한다. 기존 출처 정석 46개의 조회 정책은 유지한다.
