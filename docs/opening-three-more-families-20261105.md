# v5.18.26 · 송월·수월·명월 후속 보강

송월(D8)·수월(I4)·명월(I12)의 깊은 원자료 후속을 추가하고, 초반 미등록 응수에는 공개 엔진으로 따로 분석한 대응수를 연결한다. 선공의 돌 색과 기보 따라두기 체크에 관계없이 적용하며 판 위 반투명 주형 선택에도 저장된 후속을 표시한다.

## 원자료 후속

기존 34,749개 사실 좌표와 추천을 보존하고 6,106개를 추가해 총 40,855개를 등록한다.

| 주형 | 추가 참고 착수 | 추가 자료의 가장 깊은 자기 수 |
| --- | ---: | ---: |
| 송월 | 2,013 | 27수 |
| 수월 | 2,038 | 25수 |
| 명월 | 2,055 | 27수 |

[대만 원배포 자료실](https://587.renju.org.tw/program.htm)의 송월·수월·명월 라이브러리와 [RenLib](https://www.renju.se/renlib/)의 전체 주형 자료에서 등록되지 않은 후속을 조사했다. 원저자의 [송월](https://www.ljrenju.com/croom/d08/d08.htm)·[수월](https://www.ljrenju.com/croom/i04/i04.htm)·[명월](https://www.ljrenju.com/croom/i12/i12.htm) 설명도 대조했다.

실제 기본 추천을 따라 도달할 수 있고 원자료의 자기 수가 하나로 확인되며 전체 경로가 앱 규칙에 맞는 수순을 선별했다. 11수는 주형별 최대 1,600개를 기존 9수 부모 국면에 고르게 배분하고, 이후 13~25수는 주형별·차례별 최대 100개의 연결된 가지를 보강했다. 중앙에 가까운 응수를 먼저 검토한 것은 자료 범위를 고르는 기준이며, 수의 강도나 필승 순위를 뜻하지 않는다. 원자료의 모든 11수와 모든 깊은 응수를 수록한 것은 아니다.

선별한 6,106개는 원본 라이브러리의 해시·바이트 오프셋·전체 수순과 독립 대조했다. 양색·8대칭 조회 97,696개, 등록된 부모 연결 22,056개를 검사하고 기존 34,749개의 추천을 보존했다. 자료는 현재 앱의 양측 33 금지·44 허용·정확한 5목 규칙으로 검사하며, 원자료의 표준 렌주 평가를 현재 규칙의 승리 증명으로 옮기지 않는다. 원본 라이브러리·주석·영상·개인 자료는 배포하지 않는다.

## 엔진 분석으로 보강하는 응수

배포된 v5.18.25 공개 소스와 당시 채택 모델을 고정하고 아래 범위의 미등록 국면을 분석한다. 미채택 실험 엔진이나 개인 승리 기보를 계산 기준으로 섞지 않는다.

| 주형 | 기본 3수 뒤 미등록 상대 4수 | 대표 5수 뒤 미등록 상대 6수 | 대표 5수까지의 좌표 |

고정한 새 기본 대응 대상은 1,172개이며 회전·반사 중복을 제외하면 1,072개다. 각 국면에서 정석·저장 기보를 끄고 심층 분석에 15초 예산을 주어 대응수를 계산한다. 그 수 뒤에서는 상대 입장으로 별도의 750ms 분석을 수행한다. 예산보다 일찍 비교나 승리 수순 확인이 완료될 수 있으며 실제 시간·깊이·선택 수·소스 commit·모델 식별자·결과 해시를 보존한다.

기본 대응 1,172개와 대표 반격 뒤 후속 1,161개를 새로 등록했다. 새 항목은 총 2,333개이며 기존 2,884개와 합쳐 5,217개다. 실제 공개 엔진 조회에서 세 주형 각각 상대 4수 222개와 대표 5수 뒤 상대 6수 220개, 총 1,326국면의 대응을 확인했다.

위 대응수에 상대 분석의 1순위 응수가 이어졌을 때 다음 자기 수도 자료 밖이면 3초 예산으로 따로 계산하고 750ms 상대 분석을 다시 수행한다. 이 후속은 대표 반격 한 갈래의 7·9수 연결이며 모든 미래 응수의 전수 지원은 아니다. 3초는 사전 계산의 예산으로 앱 기능을 켜는 조건이 아니다.

선택 수·깊이·출처·비교 수까지 일치하는 완료 비교 또는 별도 규칙 검사기로 확인한 승리 수순이 있는 경우에 등록한다. 원결과에 승리가 있으면 비교 완료 여부와 관계없이 증명 전체를 재검사한다. 현재 결과와 깊이가 다른 이전 비교 정보는 완료 비교로 표시하지 않는다. 확인된 패배·상대 강제승·검증 실패·미완료 결과는 채택하지 않는다.

원자료·즉시 승리·필수 차단·확인된 반증을 우선하고, 정확히 일치하는 저장 국면에서만 사전분석 대응을 조회한다. 명시적인 심층 분석이나 저장 예산보다 긴 수동 분석은 새로 계산한다. 자료가 없는 다른 응수와 이후 국면은 기존 엔진을 사용한다. 저장된 점수·깊이·노드를 현재 탐색 성과로 옮기거나 현재 조회를 강제승 판정으로 표시하지 않는다.

## 보존과 검증

기존 사월·구월·한성·항성의 2,884개 사전분석 항목과 원래 분석 정보는 순서·좌표·증거 해시를 그대로 유지한다. 기존 포월 174개 데이터 파일도 원래 바이트를 보존한다. 저장 응수 상한을 8,192개로 늘리고 새 세 주형만 추가하며, 기존 조회·주형 선택·심층 전환 정책을 유지한다.

공개 `dist/index.html`과 이 PC의 실제 `outputs/omok.html`은 같은 공개 엔진으로 빌드한다. 개인 외형·저장 키·기보·기존 채택 모델과 별도 미완성 실험은 보존한다.
