# v5.18.34 · 실제 항성 8수 뒤의 후속 연결

선공으로 `H8 G7 F8 G8 G9 F10 H10 E7`을 두면 8수 뒤에 등록된 9수 자료와 반투명 선택지가 없었다. v5.18.33에서 확장한 항성의 대표 21수 진행은 이 판과 4수부터 다른 가지였다. 이번 변경은 위 8수 판에서 직접 출발한다. 수 번호는 양쪽 착수를 합친 전체 수다.

이제 이 판의 **9수 I9**를 바로 조회하고 선택할 수 있다. 상대의 합법 10수 216곳 모두에 11수 대응을 연결했다. 기보 따라두기 체크 없이 자동 최대 15초 모드와 반투명 선택지에 적용한다. 백 선공과 흑 선공, 회전·반사한 같은 판을 모두 지원한다.

| 추가 자료 | 개수 | 확인한 근거 |
| --- | ---: | --- |
| 원자료 S · 9수 | 1 | 원배포 좌표와 15초 완료 비교의 선택이 일치 |
| 원자료 S · 11수 | 83 | 각 추천수의 승리 증명을 별도 규칙 검사기로 재생 |
| 사전분석 C · 11수 | 133 | 승리 증명 122개, 25초 완료 비교 11개 |
| 사전분석 C · 이후 선택 후속 | 33 | 승리 증명 22개, 25초 완료 비교 11개 |
| 합계 | **250** | S 84개 + C 166개 |

완료 비교는 필승 증명과 구분한다. 9수 I9 자체와 이후 모든 상대 응수에 대한 전체 필승 수순을 증명한 것은 아니다. 자료가 없는 변화에서는 일반 엔진이 분석한다.

아래 6가지는 모두 위 실제 8수와 9수 I9에서 출발한다. 각 내 수는 실제 기본 추천과 일치하며 상대 응수·합법성·반격 검사·마지막 정확한 5목까지 확인했다.

초기 짧은 분석의 H9 변화는 11수 G11부터 미증명 비교수를 계속 선택하다 37수에서 강제 패배를 확인했다. 이 진행은 등록하지 않았다. G11 자체가 필패라는 결론으로 확대하지 않고, 미증명 11수 13개를 25초로 재분석했다. H9 뒤의 새 11수는 I11이며 실제 25수 종국까지 연결한다. 미증명 원자료 11수도 기본 추천에서 제외하고 새 분석의 선택을 사용한다.

후속에서 처음 완전한 승리 증명을 얻은 뒤에는 같은 증명의 전략을 상대 응수에 맞춰 따라간다. 매번 다른 승리 경로로 갈아타서 종국을 늦추지 않는다. 증명에서 추출한 고정수 18개는 그 한 후보를 실제 깊이 1에서 비교한 기록과 별도 승리 검증을 함께 보존했다. 다른 추천의 깊이·노드나 증명 PV 길이를 검색 깊이로 옮기지 않았다. 즉시 승리나 필수 차단은 기존 전술 엔진이 처리한다.

[대만 원배포 자료실](https://587.renju.org.tw/program.htm)의 `D1I3-2.rar`에서 정확한 8수 색 배치와 일치하는 전환을 찾았다. 원자료의 앞선 착수 순서는 다르지만 회전·반사와 돌 색의 역할을 맞추면 같은 판이다. 원래 한성 쪽의 순서·파일 해시·바이트 위치와 실제 항성 순서의 전환 근거를 보존하며, 새 자료는 9수부터만 조회한다. [원저자 항성 설명](https://www.ljrenju.com/croom/i03/i03.htm)도 함께 확인했다. 원배포의 긴 주석·전체 라이브러리·영상은 배포하지 않는다.

원자료에서 찾은 법규상 합법 후보 2,647개를 모두 추가한 것은 아니다. 이번에는 9수와 검증한 11수 84개만 원자료로 등록했다. 더 깊은 원자료 후보와 미증명 11수는 로컬에 보존한다. 직접 분석은 공개 v5.18.33 커밋 `592fd0b6a1e688289a783a450e0d251bc3c7570e`와 같은 채택 모델을 사용하며 초기 결과·반례·보강 결과를 각각 보존한다.

기존 원자료 61,441개와 발행처·과거 확장 메타데이터, 사전분석 32,212개와 기존 5개 확장 증거를 유지한다. 새 합계는 S 61,525개·C 32,378개다. 상한과 수읽기 알고리즘, 기본 3수 선택 정책, 채택 모델을 바꾸지 않는다. 과거 증명·점수·깊이는 현재 실시간 승리 판정으로 넘기지 않는다.

새 검사는 정확한 사용자 8수, 색·8방향 변환, 원자료 전환 근거, 새 C의 실제 백 선공 원결과와 정규화의 연결, 합법 10수 216곳, 선택 6가지 종국을 검사한다. 기존 433개 응수의 실제 추천과 과거 환원 경로의 영향도 확인한다. 공개 HTML과 사용자가 여는 개인 HTML을 따로 실행해 선택·클릭·되돌리기·모바일·기보 체크 해제·자료 밖 분석 및 사전분석의 명시적 심층 전환을 확인한다. 개인 외형·저장 키·기보·모델은 유지한다.
