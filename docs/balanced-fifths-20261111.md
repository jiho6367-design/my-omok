# 자료의 동등 5수 적용 · v5.18.44

선공의 5수 추천에서, 상대 4수까지의 **전체 돌 배치가 일치하는 동등 평가 자료**를 먼저 조회합니다. 별도 체크는 필요 없습니다. 후보가 여럿이면 반투명 돌과 아래 버튼에서 선택할 수 있습니다. 3수 선택과 7수 이후 기존 동작은 유지합니다.

## 출처와 평가의 뜻

출처는 喵声依旧가 2019년 7월 1일자로 작성한 [《索索夫规则 开局指南》 PDF](https://github.com/taotao568685/Renju-files/blob/master/%E7%B4%A2%E7%B4%A2%E5%A4%AB%E5%BC%80%E5%B1%80%E6%8C%87%E5%8D%972019-07-01-CHS.pdf)입니다. PDF 7–30쪽의 직접·간접 주형 상세 도표에서 사실 좌표, 대안 5수 번호, 평가와 쪽수를 대조했습니다. 각 등록 항목에 원자료 식별자·쪽수·도표 번호를 보존하며, PDF·이미지·본문은 배포하지 않습니다. 확인한 PDF의 SHA-256은 `3e6b1c1a719c031a5b2b6828a1812e768c5c8df7b6e7842ac6c80ea7963bbdb2`입니다.

자료의 ‘평형’에는 무승부 가능한 형세뿐 아니라 복잡해서 판단하기 어려운 형세도 포함됩니다. **2019년 자료의 분류를 적용한 것이며, 최신 이론이나 우리 규칙의 동등 증명이 아닙니다.** 소시르프 개국 절차 전체를 도입하지 않고, 그 자료의 5수 배치와 평가만 참고합니다.

우리 게임은 기존처럼 양쪽 3·3 금지, 양쪽 4·4 허용, 정확한 5목 우선, 6목 이상 비승리를 사용합니다. 표준 렌주의 흑·백 비대칭 금수와 다릅니다. 원자료의 흑·백 평가는 각각 선공·후공 역할로 옮겨 표시하므로 백돌 선공에서도 의미가 바뀌지 않습니다.

## 적용 기준

등록 원자료는 168개입니다. 단서 없는 동등 평가 140개와 편향·복잡성 단서가 붙은 동등권 28개를 구분합니다. 같은 판에서 조회되는 후보의 기본 표시 순서는 다음과 같습니다.

1. 동등
2. 후공 약우인 동등권
3. 복잡한 동등
4. 선공 약우인 동등권

같은 등급의 좌표 순서는 일정하게 유지하며 강약 순위로 해석하지 않습니다. 명시적인 평형 표현 없이 한쪽 우세로만 분류한 수와 판단 불명인 수는 제외했습니다. 특히 금성 D7의 `4 G9 → 5 G10 / J10`은 원문이 흑 소우세이므로 포함하지 않았습니다.

두 색의 선공과 판의 회전·반사 8가지를 지원합니다. 앞선 착수 목록만 보고 추정하지 않고, 두 선공 돌과 두 후공 돌의 전체 배치를 맞춥니다. 같은 색 돌의 착수 순서가 다른 자료도 실제 배치가 같으면 연결됩니다. 다른 4수에서는 기존 유리한 5수 책을 자동 추천하지 않고 일반 엔진 분석으로 전환합니다. 즉시 승리·필수 방어와 확인된 반박은 자료 추천보다 우선합니다. 복기에도 같은 5수 정책을 적용합니다.

자료 조회 결과는 강제승·패배·무승부 증명을 갖지 않으며 탐색 깊이·노드 수는 0입니다. 화면에 원자료 평가와 출처를 표시합니다. 이 변경은 신경망 모델 채택이나 기력 향상 판정이 아닙니다.

## 실제 조회 범위

26주형의 기본 좌표에서 빈칸 222곳을 각각 상대 4수로 놓은 **5,772개 국면**을 검사했습니다. 회전·반사와 동일 배치 전환을 포함해 25주형에서 171개 상대 4수에 자료가 연결되고, 서로 다른 4→5 대응은 273개입니다. 그중 단서 없는 동등 후보가 있는 상대 4수는 142개, 그 대응은 224개입니다. 모든 4수를 지원하는 주형은 없습니다.

좌표는 A–O에 I열을 포함하며 중앙은 H8입니다. 위 수치는 주형별 자체 도표의 등록 행 수가 아니라 **실제 전체 판 조회에서 지원하는 4수 수**입니다.

예를 들어 화월 `H8 H9 I9 I8`에서는 원도표(PDF 10쪽·책 4쪽)의 K6·H6이 후공 약우인 동등권입니다. 같은 네 돌의 반사·착수 순서 전환으로 F11·F8도 연결됩니다. `H8 H9 I9 G7`에서는 I7·G8이 단서 없는 동등 평가입니다. 반면 포월 `H8 I9 I7 G9`의 F8·J9는 이 자료에서 후공 우세인 복잡한 형세로 분류되어 동등 목록에 넣지 않았습니다. 이 국면은 일반 분석을 사용합니다.

## 검증

- 모든 168개 자료의 첫 5수 전체를 양색의 현재 규칙으로 합법성 검사합니다.
- 자료별 양색·8대칭 2,688개 변환에서 원래 5수 후보가 누락되지 않는지 검사합니다.
- 자료 밖 응수의 일반 분석 전환, 기존 3수·7수 보존, 복기, 위조·과거 증거 제거, 즉시 수와 검증 반박 우선 검사를 수행합니다.
- 작은 브라우저 화면에서 등급 구분·출처·선택 버튼과 흑·백 선공을 확인합니다.
- 공개·개인 빌드는 같은 엔진을 사용하며, 기존 채택 모델·개인 외형·저장 키·기보는 유지합니다.
