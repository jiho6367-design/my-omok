# 후보3의 K4 핵심 8판 결과

후보3(v5.18.20)은 핵심 8판에서 선공 5승·후공 3승이었다. 기존 패배 사례 I4는 선공 승리로 전환했지만, K6는 패배했고 기존 승리 사례 I5·J6도 보존하지 못했다. 따라서 이 후보는 최종 합격 조건을 충족하지 못했으며 나머지 16판과 앱 반영을 진행하지 않았다.

## 고정 조건과 실제 결과

첫 수 K4, 작은·큰 사각형 테두리의 지정 8개장, 양쪽 자동 최대 15초, 동시 한 판으로 진행했다. 모든 판에 같은 소스 `8cfea302caee6c9ff5e75a352158e0460031cca5c8195a3ebc4f8f3fc7c65f5f`, 동결 공개 HTML `7f25a261ca27e68ad8f24fcddd2f5016d0208e3fa48f3e1dca792668e4dd7c6a`, 기존 모델 8119를 사용했다. 모델 전체 SHA-256은 `fce1c849e6eb05a1ec839550a2dc29ca509b0c7ce0d7ea6150095eeee1a91932`다.

강제승·강제패배 표시는 중간 진단으로만 사용했다. 8판 모두 합법적인 실제 정확한 5목으로 종료됐고, 총 299수 중 고정 시작수 16개를 제외한 283수를 엔진이 추천했다. 기록된 분석 응답의 최댓값은 14,027ms였다. 이 최댓값은 이번 대국의 관측값이며 모든 환경의 시간 보장이 아니다.

대국 실행기·모델·규칙·소스·HTML을 고정하고 기보 행의 해시 연결, 체크포인트와 원본 로그의 모든 수 일치, 착수 순서, 합법성, 예상 수순, 실제 종료를 대조했다. 큰 증명 객체가 있는 기존 기보는 수별로 읽어 확인했다. 실제 자식 실행은 종료 코드 0으로 끝났고 브라우저 연결 종료·남은 컨텍스트 0개를 확인했다. 검증 명세와 최종 결과 보고 도구도 각각 종료 코드 0이었다. **도구의 정상 종료는 후보의 기력 합격을 뜻하지 않는다.**

대국의 실행 환경은 Node 24.19.0·Edge 156.0.4314.50이었다. 앞선 CPU 3/5 비교와 모드 검사는 Edge 156.0.4314.42에서 실행됐으므로 두 단계의 브라우저 버전을 같다고 표시하지 않는다. 이번 8판 안에서는 같은 실행 환경을 유지했다.

## 판정과 보존

기존 22승 가운데 이번 지정 개장에 포함된 6곳은 4곳 유지·2곳 실패였다. 다른 16곳은 실행하지 않았으므로 보존 여부가 미확인이다. I4 전환 한 건이나 기능 검사 통과를 전체 기력 향상, 24판 통과 또는 후공 방어의 일반적인 개선으로 확대하지 않는다. 같은 엔진끼리의 이번 결과만으로 어느 쪽 판단의 변화가 전체 기력에 유리한지도 확정할 수 없다.

원본은 로컬 `work/k4-three-stages-20261028/retention/native-auto15/`에 보존했다. 핵심 8판 명세 `core8-gate.json`의 SHA-256은 `e9dffd415348906ead732cdd52cd7c08f8e9538f6df6092f962eabdce0ba37a0`, 최종 보고서 `final-report.json`은 `e2d0c822e5458e121a9064cc5beac31b558e78e9c98a4e9151e31b07e45f7f38`이다. 나머지 16판 허용과 최종 합격 값은 모두 false다.

미채택 소스·검사·빌드·새 대국 원본은 로컬에 유지한다. 사용 중인 앱 v5.18.10의 SHA-256 `c89d82c623c8e7dd15b139d9379ce43fd84ab2d0c27093a445ba904c26ad6bf0`, 개인 외형과 기존 저장 설정은 유지했다. 남은 추가 후보 한 개를 사용하기 전에 I5·J6의 실제 공통 국면과 K6의 평가 변화 원인을 별도로 확인한다.
