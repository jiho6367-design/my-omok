# v5.18.21 · 리얼오목과 보충 정석

[리얼오목[Real5mok]](https://www.youtube.com/channel/UCEkkLEqyP0JxuLzuvUxtwfg)의 전용 강의 8편과 관련 영상 11편을 전체 가용 자막·전 구간 20초 간격 화면으로 검토하고, 선택한 도표의 번호나 실제 착수 순서를 원본 화면과 대조했다. 모든 순간 도표를 좌표화했다는 뜻은 아니다. 오목기사임진욱의 정석 0~11강도 검토해 유리한 변화만 선별했다.

중복과 기존 선택 충돌을 제외한 새 참고 착수는 **220개**이며, 기존 **31,755개**를 순서·좌표·출처 그대로 보존해 총 **31,975개**다. 이번 추가는 오목기사임진욱 120개, 리얼오목[Real5mok] 100개다. 영상의 44 금수·백 장목·시간승·패착 사례를 이 앱의 필승으로 가져오지 않았다.

리얼오목의 [쉬운 포월](https://www.youtube.com/watch?v=uH7hGikPy4A), [협계월 1부](https://www.youtube.com/watch?v=hjdc7rP0VuY), [협계월 2부](https://www.youtube.com/watch?v=8XBSCXHWCBQ), [협계월 3부](https://www.youtube.com/watch?v=jccFh9eXS5E), [포월 응수 설명](https://www.youtube.com/watch?v=85-E_DB-Wns), [서성 짧은 수순](https://www.youtube.com/watch?v=v8-mNakvDrk)에서 확인 가능한 후속을 등록했다. 상대 연결 차단과 자기 공격 연결, 성급한 삼 대신 공간을 확보하는 준비가 설명의 핵심이다. 이 설명 자체를 무조건적인 승리 점수로 사용하지 않는다. 기보 밖의 열린 셋 검증은 아래 v5.18.20 엔진 동작을 유지한다.

다른 3·5수를 수동 선택한 뒤에만 맞는 조건부 국면도 있다. 기존 화월·포월 기본 3수와 두 정확한 추천 선택은 유지하며, 기본 포월 5 J8 뒤 **46/220 지원·174 미지원**도 그대로다. 기보 따라두기 체크 없이 적용하고 등록되지 않은 국면은 일반 분석으로 넘긴다. 모든 주형·응수의 필승 또는 모든 새 참고의 기본 경로 연결을 뜻하지 않는다.

새 후속 전체의 양색·8대칭 조회와 기존 v5.18.20 자료 전체의 동일성, 두 기본 선택·필수 즉승/방어·174개 미지원 범위를 회귀 검사한다. 실제 사용자 실행본에서도 새로운 조건부 국면을 1초 내 표시하고 기보 체크 없이 동작하는지 확인한다.

# v5.18.20 · 공개 강의 후속과 열린 셋 검증

공개 강의의 번호 도표와 실제 착수 순서를 대조해 **참고 착수 1,197개**를 추가했다. 기존 30,558개는 출처·좌표·변환 정보까지 보존하며 총 **31,755개**다. 포월·화월·운월·은월·산월·서성·명성·우월·람월·명월의 후속을 확장했다. 기존 21개 허용 주형과 5개 제외 주형의 정책은 유지한다.

등록된 정확한 판에서는 선공의 돌 색에 관계없이 기보 따라두기 체크 없이 조회한다. 회전·반사를 포함하며 일부 자료는 **39수**까지 있다. 다른 5수나 수순을 수동으로 선택한 뒤에만 도달하는 조건부 국면도 포함한다. 모든 새 항목이 기본 3수부터 자동으로 이어진다는 뜻은 아니다. 실제 선택을 따라 잇는 포월·산월·우월의 긴 경로는 별도로 검사했다. 등록 국면 밖에서는 기존 탐색을 사용한다.

## 포월 174개 응수의 범위

`H8 I9 I7 G9 J8` 뒤 합법 상대 6수는 220개이며, 7수 자료 지원은 여전히 **46/220**, 미지원은 **174개**다. 이번 강의에서 이 기본 5수 뒤의 새 6수 응수에 대응하는 검증 가능한 좌표를 확보하지 못했다. 깊어진 후속, 다른 5수의 응수, 회전·반사를 새 6수 지원으로 합산하지 않는다. 미등록은 패배 판정이 아니다.

## 두 정확한 국면의 추천 선택

- 화월 `H8 H9 I9 G7` 뒤 **5 J10**을 선택한다. [오목기사임진욱 화월 1부](https://www.youtube.com/watch?v=rRBqlbeB7LI&t=56s)의 두 대안 설명과 실제 번호 도표를 대조했다. 기존 서로 다른 5수 때문에 일반 탐색으로 넘어가던 정확한 국면만 해소한다.
- 포월 `H8 I9 I7 G9 J8 K9` 뒤 **7 H9**을 선택한다. [오목랭커 포월 2부](https://www.youtube.com/watch?v=TMcwVpTREHg)의 백 연결 차단과 9 I5 준비 수순을 대조했다. 기존 7 J6 자료와 그 이후 수순도 원래의 조건부 참고로 보존한다.

우선 선택은 그 한 차례의 정확한 판에만 적용하며, 이전 수·다른 판에 평가나 승리 판정을 부여하지 않는다. 동급 우선 자료가 서로 다른 수를 제시하면 일반 탐색으로 넘긴다. 기존 대안의 삭제나 출처 전체에 대한 우열 평가는 없다.

## 기보 밖에서도 사용하는 엔진 변경

[오목기사임진욱 은월 강의](https://www.youtube.com/watch?v=zLnoROhirVk&t=184s)의 공격 연결을 현재 규칙으로 검토하며, 기존 자동 분석이 열린 셋 후보를 빠뜨리는 국면을 확인했다. 자동·심층 분석은 기존 두 돌의 지지를 이용해 합법적인 열린 셋을 만드는 후보를 별도로 찾는다. 다음 연장 수와 정확한 5목 양 끝의 합법성도 검사한다. 같은 지지를 이용하는 후보 중 한 수를 제한된 증명 작업에 보낸다.

형태 자체에 승리 점수를 주지 않는다. 기존 검증기로 **상대의 모든 합법 응수**에서 승리를 확인하고 최종 증명 검사까지 통과해야 강제승을 반환한다. 시간 부족·불완전·실패한 검증은 일반 탐색으로 이어진다. 이 작업은 자동·심층 예산의 최대 8%, 상한 1,200ms 안에서 수행하고 사용한 시간은 나머지 탐색 예산에서 뺀다. 3초 활성 조건과 기보 따라두기 의존성은 없다. 1초 빠른 모드의 탐색 정책은 유지한다. 즉시 승리와 필수 차단이 먼저다.

좌표를 고정하지 않았다. 두 색·8대칭, 후공 차례와 멀리 다른 돌을 추가한 판에서도 실제 탐색과 독립 증명 재검사로 확인했다. 이 검증은 해당 전술의 일반화 사례이며 모든 유사 모양에서 필승을 보장하지 않는다.

## 출처와 규칙

확인 자료는 [오목기사임진욱](https://www.youtube.com/@오목기사임진욱), [오목랭커](https://www.youtube.com/@parkwoongbae), [종빈](https://www.youtube.com/@이종빈)의 공식 공개 강의·관련 실전이다. 새 좌표별 영상 주소·시점·도표 식별값을 배포 데이터에 남긴다. 주요 자료에는 [포월 1부](https://www.youtube.com/watch?v=mnmPhq5y4mM), [화월](https://www.youtube.com/watch?v=t9VxuIPkBXA), [운월](https://www.youtube.com/watch?v=OMNCm-_b4oA), [종빈 포월 2부](https://www.youtube.com/watch?v=UiIzk3K2xx0), [종빈 우월·운월 설명](https://www.youtube.com/watch?v=oh41Jg1WdvU)이 있다. 영상 제목 대신 실제 첫 세 돌로 주형을 식별한다.

앱의 규칙은 양쪽 33 금지, 44 허용, 정확한 5목만 승리다. 표준 렌주의 백 33 허용·백 장목 승리·흑 44 금지에 의존하는 결론을 가져오지 않는다. 예를 들어 종빈 포월 번외의 한 실전은 백 마지막 수가 6목이라 여기서는 승리가 아니며, 다른 실전의 백 18수는 이 앱의 33 금수다. 이런 전체 승리 수순은 채택하지 않았다. 포월·화월 강의의 다른 5수들을 임의로 이어 붙이지 않았고, 잘못된 예·순서가 불확실한 도표·새 자료 간 미해결 선택도 제외했다. 참고 자료에는 `reference:true`, `proven:false`를 유지한다.
