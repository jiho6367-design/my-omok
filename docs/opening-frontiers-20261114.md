# 정석 종료 뒤 검증 전략 확장 · v5.18.60

현재 추천을 둔 뒤 상대가 유일한 5목 승리점을 막았을 때, 자료 조회와 즉시 전술 판정이 모두 끝나 일반 탐색으로 넘어가던 국면을 조사했습니다. 아래 15주형의 **214개 정확한 13~33수 국면**에서 모든 합법 응수에 대한 승리 전략을 추가했습니다. 각 전략의 최장 종국은 전체 17~37수입니다.

자료에 돌이 있다는 이유로 필승으로 처리하지 않았습니다. 현재 기본 추천이 해당 수와 일치하는지, 다음 상대 방어 뒤 세 모드의 조회가 실제로 비는지 먼저 확인했습니다. 각 새 전략의 원본과 압축 실행 자료를 각각 두 색·8가지 회전/반사에서 재생하고, 독립 증명 검사기와 별도의 기하학 규칙 검사기를 통과시켰습니다. 최초 상대 응수와 원증명 핀 연결 693,280건도 확인했습니다.

실제 FCE 모델을 지정한 엔진에서 새 214개 전략의 시작점·강제 차단 뒤 후속·종국을 10·15·25초 모두 검사했습니다. 각 경로에서 원증명 식별자와 선택수가 유지됐고, 종국은 실제 정확한 5목으로 마무리됐습니다. 이 검사는 저장 전략의 재사용을 확인한 것으로, 일반 엔진의 전체 기력 향상을 뜻하지 않습니다.

## 포월 초반과 추가 후속의 범위

포월의 특정 6돌 부모판에서 검토한 7수 E7(회전하면 I5)은 아직 일반 탐색 후보입니다. 같은 사진 국면의 실제 실행에서 10초는 I5, 15·25초는 F8을 선택했습니다. 공통 탐색 깊이의 후보 점수는 같았으며, 뒤의 두 모드가 한 단계 더 탐색을 완료한 차이였습니다. 이 관측은 어느 쪽의 승리 증명이나 승률을 뜻하지 않습니다. **7수 이후 상대의 모든 응수에 이긴다는 증명은 아직 없으며, 7수를 엔진 검증 무적수로 승격하지 않았습니다.** 다른 렌주 규칙의 외부 엔진 평가는 준비수 후보를 고르는 데만 사용했습니다.

별도로 원거리 8수 A1 분기의 정확한 13수 K8·15수 J9·19수 I6와, 강한 8수 F7로 이어지는 다른 분기의 정확한 25수 G12·27수 E10·29수 D11부터 완주하는 전략을 검증했습니다. 앞의 원거리 분기는 최장 전체 45수, 뒤의 세 전략은 최장 전체 53수입니다. 이 시작점 이전의 모든 상대 응수나 모든 내 선택이 승리한다는 뜻은 아닙니다. 각 등록 시작점부터는 상대 응수에 따라 해당 증명의 가지를 조회합니다.

## 보존과 실행 범위

기존 283개 전략·2,377개 노드의 좌표·순서·원증명 식별자를 보존했습니다. 원래 무적수·정석과 별도 동등5수 선택, 개인 저장 자료, 신경망 모델도 유지합니다. 새 자료를 담도록 응수 연결 상한만 393,216개로 늘렸고, 53수 종국에 필요한 저장 전략의 52수 프로필을 명시적으로 추가했습니다. 기존 40·42·46수 프로필과 일반 탐색·원정석의 40수 범위는 그대로입니다.

신경망 모델은 기존 FCE 그대로입니다. 새 자료의 `historicalModelSha256`은 출처 실행 앱의 모델 식별자이며 발견 모델을 일괄 뜻하지 않습니다. 모델 없는 유한 증명과 모델을 지정한 원본 Reader 증명 조각의 합성을 [증명 출처 정보](opening-proof-provenance-20261114.json)에 구분했습니다. 발견 보조 탐색 코드는 제품 Reader에 반영하지 않았습니다. 모델의 평가 점수, 전 응수 승리 증명, 현재의 즉시 조회 수치는 서로 구분합니다.

등록 전략의 마지막 강제 수순 뒤에는 저장 조회가 소진되더라도 현재 판의 즉시 5목 판정으로 끝냅니다. 새 52수 프로필은 이전 46수 프로필을 자동 연장하지 않습니다. 아직 검증되지 않은 정확한 국면은 일반 탐색을 사용하며, 주형 이름만으로 필승을 표시하지 않습니다.
