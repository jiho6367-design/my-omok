# 자동·심층 시간 조건 분리 검증 · 2026-10-30

자동 최대 15초와 심층 최대 25초에서 미채택 후보를 검증했다. 자동 핵심 8판은 선공 5승·2패·1무, 심층은 5승·3패였다. 두 모드 모두 채택 기준에 미달해 나머지 16판으로 넘어가지 않았다. **기존 앱과 빠르게 1초 엔진, 공개 릴리스 v5.18.10을 유지했다.**

같은 기존 채택 모델과 규칙을 사용했으며 추가 수읽기 후보나 좌표별 예외는 만들지 않았다. 후보 소스 식별자는 `0c68d909e21fbf072ec36055f8d27675ef5d6f3c6f05a48b08cfe92911a221fc`다. 이 기록은 미채택 연구 결과이며 새 엔진 릴리스가 아니다.

## 기능과 실제 시간

기존 후보의 1.5초 완료 깊이 실패는 보존했다. 이를 자동·심층의 실패로 대신하지 않고 실제 시간 조건으로 평가했다. 보존한 구 Reader의 원본 1.5초 사례는 통과했다.

원래 78개 기능 검사 명령 중 같은 입력 해시의 선행 57개 성공 근거를 재사용하고 후속 21개를 실행했다. 최신 후보 검사 사본에서는 기존 1.5초 사례 한 곳의 완료 깊이 조건만 분리했다. 합법성·허위 패배 방지·보드 복원과 나머지 조건은 유지했다. 이를 원래 단시간 성능 검사 통과라고 표시하지 않았다.

모델을 사용하지 않은 생성 국면의 native 검사 368단계(강제승 16·필수 방어 관련 즉시 판정 352), 신경망 점수 705개·특징 벡터 1,410개·시간 종료 복원 6개를 확인했다. 고정 4국면에서 구·신 엔진과 두 모드를 조합한 실제 앱 분석 16회도 완료했다. 일반 탐색 12회는 완료된 비교를 반환했고 필수 방어 4회는 즉시 반환했다.

최신 후보는 같은 시간의 구 엔진보다 완료 깊이가 낮은 국면도 있었다. 탐색 의미가 달라 깊이 차이를 속도 비율로 환산하지 않는다. 기능 검사 통과와 실제 시간 내 반환은 기력 향상을 뜻하지 않는다.

## 핵심 8판 결과

첫 수 K4, 아래 후공 2수를 고정하고 양쪽 자동 또는 양쪽 심층으로 한 판씩 진행했다. 괄호는 실제 착수 수다. 최종 엔진 판정은 다음 추천 돌을 두기 전에 기록했다.

| 후공 2수 | 자동 최대 15초: 선공 결과 | 심층 최대 25초: 선공 결과 |
| --- | --- | --- |
| K5 | 패 (55) | 패 (22) |
| I3 | 패 (100) | 승 (13) |
| I4 | 무 (225) | 패 (84) |
| I5 | 승 (21) | 승 (15) |
| M5 | 승 (11) | 승 (13) |
| J6 | 승 (15) | 승 (13) |
| K6 | 승 (13) | 승 (13) |
| M6 | 승 (34) | 패 (36) |
| 합계 | **5승·2패·1무** | **5승·3패** |

자동은 이전 종료 프로토콜에서 완료된 K5·I3·I4·I5·M5의 원본 5판을 변경하지 않고 참조하고, J6·K6·M6은 새 종료 프로토콜로 진행했다. 미완료 수순이나 캐시는 가져오지 않았다. 자동 8판 전체를 새로 다시 둔 결과로 표현하지 않는다. 심층 8판은 모두 새 대국이다.

자동의 7판과 심층의 8판은 정합적인 최종 엔진 강제승·패배 판정으로 종료했다. 자동 I4 한 판은 실제 225수 만판 무승부다. 직접·예상 조기 무승부 종료는 신규 11판에서 발동하지 않았다.

자동은 기존 22승 중 이번 핵심군의 6판을 확인해 I5·M5·J6·M6의 4승을 보존했고 K5·I3은 패했다. 심층은 같은 6곳 중 I3·I5·M5·J6에서 선공이 이겼고 K5·M6에서 졌다. 기존 심층 24판 기준 결과가 있는 것처럼 가정하지 않는다. 각 모드의 나머지 16곳은 미검증이다.

K6는 두 모드 모두 선공 승리로 전환됐지만 I4는 자동 무승부·심층 패배로 승리 전환에 실패했다. 각 핵심 8판 전승 조건이 충족되지 않아 각 나머지 16판은 실행하지 않았다. 24판 검증 성공이나 기존 22승 전체 보존으로 기록하지 않는다.

자동 분석 465회와 심층 분석 201회는 시간 검사를 통과했다. 두 모드 모두 최대 적용 시간 초과와 모드 상한 초과는 0ms였다. 검증이 허용한 250ms는 콜백 전달·운영체제 지연이며 엔진 계산 예산을 늘리는 허용치가 아니다.

## 종료 판정과 해석

정합적인 최종 강제승·패배 판정이면 추천 돌을 두기 전에 종료한다. 이는 운영 엔진 판정이며 모든 상대 응수를 따로 전개한 독립 증명은 아니다. 진행 중 후보나 높은 점수만으로 종료하지 않는다.

사용자 요청으로 만판 이전의 무승부 종료도 구분해 허용했다. 4방향 5칸 창 572개를 검사해 양쪽 모두 향후 정확한 5목을 만들 수 없으면 직접 무승부로 판단한다. 80수 이상·적은 후보 창·최근 연속 완료 비교와 현재 최종 분석의 정합적인 완료 조건을 함께 사용하는 예상 무승부는 추정으로 따로 기록하며 승리로 세지 않는다. 실제 만판 무승부도 별도로 보존한다.

원래 자동 I4 225수 기록에 새 정책을 사후 적용하면 178수 뒤 직접 무승부가 성립한다. 마지막 47수를 생략할 수 있었다는 사후 분석이며 새 대국이나 이미 달성한 시간 절약 실적이 아니다. 원본 225수 종료는 변경하지 않았다.

I3는 자동 패→심층 승, I4는 자동 무→심층 패, M6은 자동 승→심층 패였다. 긴 분석이 항상 우수하다는 결론은 지지하지 않는다. 같은 후보 엔진끼리 양측 모두 바뀌는 대국이므로 선공 공격과 후공 방어의 기여를 분리한 평가도 아니다. 일부 국면이나 대국의 승리를 전체 기력 향상으로 확대하지 않는다.
