# 후공 승리 기보 재사용 · 2026-11-01

v5.18.12는 완성된 후공 승리 기보를 다시 활용하는 기능을 추가한다. 「기보 그대로 따라두기 (선택)」을 켜면 현재 판과 차례가 등록 기보에 일치할 때 기록된 다음 수를 추천한다. 회전·반사와 돌 색 교환을 지원하며, 선후공 역할은 별도로 대조한다. 대칭이 겹치는 첫 배치에서는 원래 기보의 방향을 우선한다.

v5.18.13부터 기본 해제이며 v5.18.12의 자동 활성화 상태도 최초 갱신 시 한 번 해제한다. 등록 기록은 보존하며 이후 직접 켠 선택은 유지한다. 이전 형식 JSON 백업은 자동으로 활성화하지 않는다. 상대의 다른 응수에도 적용하는 엔진 변경은 [닫힌 공격 준비 검증](closed-preparation-proof-20261101.md)에 설명한다.

## 사용

후공이 정확한 5목으로 이긴 기보를 선택하고 「이 기보 등록」을 누른다. 「등록 기보 보기」에서 해당 판을 다시 열거나 수순을 삭제할 수 있다. 기록은 기존 브라우저의 기보 저장 공간에 보관하며 JSON 내보내기에도 포함된다. 기보는 최대 128개이고 PASS가 없는 완성된 후공 승리만 등록한다.

상대가 등록 수순과 다른 판을 만들면 기록 수를 강제하지 않고 일반 엔진으로 분석한다. 자기 즉시 승리와 상대의 다음 5목을 막는 필수 수가 기록 추천보다 우선한다. 이미 검증된 패배 수도 기록에서 다시 채택하지 않는다. 처음부터 필승을 증명한 정석이나 신경망 재학습 결과로 표시하지 않는다.

화면은 「기보 활용 · 후공 승리 수순」을 일반 수읽기 완료나 강제승과 구분한다. 탐색 깊이·완료 비교·승리 증명 값을 기록 결과에 붙이지 않는다. 유효한 과거 승리도 상대가 다르게 대응하면 같은 결과를 보장하지 않는다.

## 개인 기록과 공개 빌드

사용자가 제공한 원본 완성 기보는 PC의 로컬 자료로 보관한다. 개인 실행본은 선택적으로 초기 기보를 포함할 수 있지만 공개 HTML은 빈 초기 목록을 사용한다. 개인 외형·기보 저장 키·기존 채택 모델은 유지한다. 공개 저장소에는 범용 재사용 기능과 작은 생성 검사 자료만 포함한다.

## 검증

생성한 짧은 합법 대국으로 회전·반사·색상과 선후공 역할, 기보 이탈, 불법 수·미완료·중간 종료 거부를 검사한다. 엔진 검사는 즉시 승리·필수 방어·검증된 반증 우선, 멀리 있는 합법 기보 수, 기록 해제와 위조된 비교·증명 정보 제거를 확인한다. 빌드 검사는 개인 기보가 공개 HTML의 바이트에 영향을 주지 않는지와 잘못된 초기 자료가 기존 앱을 덮어쓰기 전에 거부되는지 확인한다.

실제 개인 기보는 별도 로컬 브라우저 검사에서 모든 후공 차례의 추천과 재시작 후 중복 없는 보존을 확인한다. 이 개인 대국은 공개 CI의 입력이나 새 모델 채택 근거로 사용하지 않는다.
