# v5.18.37 조건부 승리 전략 보강

v5.18.37은 기존 전략을 보존하면서 다른 16주형과 실제 사용자 항성 기보의 후속을 보강한다. 새 자료의 전체 증명 감사와 분리 빌드의 추천·반투명 선택·클릭·이어두기 검사를 완료했다. 실제 배포 파일의 실행과 게시 검사는 아래 범위를 기준으로 별도 출시 기록에 남긴다.

기존에 등록된 221개 시작점과 1,142개 노드의 값·순서·ID를 모두 보존하고, 다른 유리한 16주형의 27개 시작점과 실제 사용자 항성 분기의 15수 시작점 1개를 추가한 249개 전략을 검증했다. 등록된 시작점에서는 상대가 다르게 응수해도 같은 원증명의 조건부 전략을 따라가도록 후속을 연결한다. 이 범위는 등록된 전략에 한정되며, 모든 실시간 분석에서 새로 얻는 증명을 자동으로 저장하는 기능은 아니다.

지원 대상인 유리한 21주형과 불리·균형 5주형의 임시 제외 정책은 유지한다. 이번 16주형의 일부 정확한 부모판을 보강한 결과이며, 해당 주형 전체나 모든 중앙 선공판의 필승을 증명한 것은 아니다.

## 다른 16주형의 27개 시작점

각 시작점은 실제 기본 추천의 5·7·9·11수와 부모 연결을 조사해 선정했다. 원자료의 11수 추천 자체와 그 뒤 전체 조건부 증명을 현재 규칙으로 검증했다. 같은 판에서 다른 수가 이기는 증거로 원추천수를 승리 처리하지 않았다.

25개 시작점에서는 상대 12수의 확인한 3개 응수씩, 총 75개 정확한 13수 부모판에서 등록된 기본 추천이 끊기는 지점을 확인했다. 화월 2개는 기존 13수 추천이 원증명과 같았지만, 그 다음 상대 14수에 대한 15수 후속이 끊겼다. 단순히 새 시작점 개수를 세는 대신 실제 후속 공백이 있는 27개를 선정했다.

위 75개는 공백을 직접 확인한 표본 범위다. 새 조건부 증명 자체는 각 고정 11수 뒤의 모든 합법 상대 응수를 포함하며, 최종 통합 그래프에서 전체를 다시 재생했다. v37 통합 API 검사에서 이 75개 부모판의 13수 추천과 화월의 합법 14수 424곳의 15수 후속이 나타남을 확인했다.

## 실제 사용자 항성: 정확한 15 I6

사용자의 선공 돌이 백인 다음 기보에서 출발한다.

```text
1 H8   2 G7   3 F8   4 G8
5 G9   6 F10  7 H10  8 E7
9 I9  10 H7  11 I7  12 F7
13 D7 14 F9  15 I6
```

이번에 추가한 증명은 **이 정확한 14수 부모판에서 15 I6 자체**에 대한 것이다. 그 뒤 흑 16수의 합법 210곳과 모든 필요한 후속 방어를 포함한 완전한 조건부 전략을 검증했다. 정규화 과정에서 같은 하위 전략을 공유하되 선택수·부모판·quiet/forced/VCF의 의미는 바꾸지 않았다. 양색과 D4 8변환의 전체 증명 16건도 최종 통합 그래프에서 새로 통과했다. 이 전략의 보수적 최대 명시 선택수는 전체 33수, 즉시승 처리까지 포함한 종국 상한은 전체 35수다.

이 사실은 **11 I7 자체 또는 9 I9 전체의 필승 증명으로 승격되지 않는다.** 다른 상대 12수·14수까지 모두 이 전략에 포함되는 것은 아니다. 별도 13수 분할 후보와 추가 API 분석은 이번 등록 범위에 넣지 않았다.

F9에 놓인 상대 돌은 증명의 조건에도 영향을 준다. 원 후속의 한 판에서는 흑의 H11 차단이 F9-G10-H11 및 H11-I10-J9 두 열린 3 축 때문에 금수다. 상대 14수를 O15로 바꾸면 한 축이 사라져 같은 H11이 합법 차단이 된다. 백의 즉시 완성점이 같아도 원증명을 그대로 옮길 수 없는 이유다. F9와 다른 합법 14수 211곳을 교환한 후보는 전체 증명 검증을 통과하지 못했으며 등록하지 않았다. 이는 그 고정 전이 전략의 실패이고, 15 I6 자체가 필패라는 증거는 아니다.

## 규칙·전체 증명 감사·측정값

규칙은 `15x15-exact5-both33-v1`이며 양쪽 돌에 정확한 5목과 33 금수를 적용한다. 일반 렌주 원평가를 그대로 필승으로 옮기지 않았다. 각 원추천수의 합법성, 정확한 돌 색·기보 순서·좌표 변환, 모든 현재 합법 방어, 강제 위협 및 VCF 종결 조건을 독립 규칙 재생으로 확인했다.

전체 249개 × 양색 2가지 × D4 8변환인 3,984건의 증명 근거는 다음처럼 구분한다.

| 범위 | 전체 증명 건수 | 이번 감사의 실행 방식 |
| --- | ---: | --- |
| 기존 221개 | 3,536 | 모든 원노드·시작점·ID가 정확히 같음을 대조한 기존 증거 재사용 |
| 다른 주형 27개 | 432 | 최종 249개 그래프에서 새 전체 재생 |
| 정확한 항성 15 I6 1개 | 16 | 최종 249개 그래프에서 새 전체 재생 |
| 합계 | 3,984 | 새 재생 448건 + 기존 증거 재사용 3,536건 |

과거 새 28개를 따로 검사했던 결과는 원증거 계보로 보존했으며, 이번 448건에 중복해서 더하지 않았다. 전체 증명 재생은 선택한 대표 기보 한 줄의 종국 확인과 구분한다. 이 감사는 엔진의 새로운 제한시간 탐색이나 속도·강도 비교가 아니다.

항성 15 I6 원분석의 명시 예산은 **25,000ms**다. 실제 경과가 약 2.8초였다고 3초 예산 자료로 바꾸지 않았다. 원대표 변화(PV)는 고정 I6를 포함해 17수다. 별도로 계측한 증명 탐색 방문 최대는 I6를 둔 뒤의 진입판에서 추가 19수이고, 고정 I6까지 부모판 기준으로 포함하면 20수다. 해당 호출의 242,849노드 역시 원분석의 측정값이다. 후보 비교 탐색은 실행하지 않았으므로 비교 깊이 완료를 주장하지 않는다.

PV 17수와 방문 최대 19수는 서로 다른 값이다. 과거 보고 깊이나 PV 길이를 새 검색 깊이로 표시하지 않고, 과거 proof/depth/nodes/score를 현재 조회의 실시간 결과로 올리지 않는다. 등록 전략 조회의 실시간 `depth/nodes/score`는 0, `proof`는 null, `proven`은 false이며 원증명 식별자와 조회 커서를 별도로 전달한다. 과거 예산은 원자료의 명시 예산 메타데이터다.

원 H7 분석 당시의 기준 커밋과 기록은 수정하지 않았다. 실제로 불러온 8개 소스의 보존 바이트가 v36 배포 커밋과 모두 같음을 별도 대조해 새 정규화 전략의 소스 식별자를 연결했다. 분석 시점과 이후 배포 시점이 같았다는 뜻은 아니다.

## 보존한 데이터와 용량

원자료 S는 61,525개, native C는 32,602개 그대로이며 이번 S/C 행 추가는 0개다. 기존 채택 모델의 SHA-256은 `fce1c849e6eb05a1ec839550a2dc29ca509b0c7ce0d7ea6150095eeee1a91932`로 유지한다. 기존 221개 root 및 1,142개 node를 앞부분에 그대로 두고 뒤에 새 자료를 붙였으며 원증거를 삭제하거나 다시 번호 매기지 않았다.

| 전략 노드 | 1,497 | 65,536 |

| JSON 파일 크기 | 939,757 bytes | 8 MiB |

조회 입력 기보는 40수 미만이며 등록 전략의 명시 내 선택수는 39수 이하이다. 상대 40수 뒤 기존 즉시승 처리가 완성하는 41수 종국은 별도 상한으로 유지한다. 비전술적인 41수 정책을 추가하거나 용량을 올리지 않았다.

249개 시작점의 원선언 예산은 3,000ms 128개, 15,000ms 27개, 25,000ms 94개다. 이는 기존 221개와 새 28개에 연결된 과거 증명 자료의 예산 분포이고 현재 실시간 분석의 실행 횟수·예산·노드가 아니다. 기존의 짧은 미증명 자료에 대한 자동 모드 허용 기준도 유지한다.

## 통합 실행 검사의 범위

최종 249개 자료를 탑재한 엔진 API 검사에서는 1,869개 조회를 실행했다. 기존 실제 사용자 8수의 215개 첫 응수, 전체 249개 시작점의 원증명 연결, 다른 주형의 새 13수 공백 75개와 화월의 15수 후속 424개, 정확한 항성 15 I6 뒤 상대 16수 210곳을 확인했다. 즉시 필수 차단 12개는 일반 사전조회와 구분해 합법 차단점·원전략 pin·반투명 선택 좌표를 확인했다. 이 검사는 새 제한시간 탐색을 실행한 강도 비교가 아니다.

분리 개인 빌드의 브라우저 검사에서는 다른 주형 27개 선택 진행을 원래 11수의 자료 ID에서 시작해 전체 15수 또는 21수 종국까지 이어 두었다. 실제 사용자 8수에서 H7/F7/D7/F9를 거쳐 15 I6를 클릭하고, 같은 원증명을 유지해 전체 35수 종국에 도달했다. 총 보드 클릭 101회, 목록 클릭 1회, undo 1회 및 390px 화면을 확인했으며 페이지 오류는 0개였다. 기보 따라두기는 끄고 자동 모드·수동 저장값 1,000ms에서도 적용을 확인했다. 210개 상대 응수는 별도 API 검사 범위이며 210판을 모두 브라우저에서 끝낸 것은 아니다.

기존 221개 브라우저 회귀와 전략 모듈·엔진 연결·자동 허용·검색 계측·모델 빌드 계약도 별도로 통과했다. 실제 사용 경로와 저장소 개인 출력의 해시·버전·동일 기보 실행, 공개 빌드의 실행, 게시 전 경계 검사 및 Git 동기화 결과는 출시 기록에 묶는다. 전체 npm 검사나 새 15초 대국 강도 비교를 수행했다는 뜻은 아니다.
