# 후보4의 연결 공격 탐색과 미통과 결과

후보4(v5.18.21)는 연결 공격 후보의 누락을 보완했지만 전체 기능 검사에서 완료 깊이 조건을 통과하지 못했다. **미채택 상태이며 앱에 반영하지 않았다.** 이 기록의 기준은 2026-10-29 19:59:29 UTC에 종료된 세 번째 전체 검사다.

- Reader SHA-256: `076ee6524213413ad227de125b019eee231091475a138e406971b273ec0eb410`
- 모델: 기존 8119, 전체 SHA-256 `fce1c849e6eb05a1ec839550a2dc29ca509b0c7ce0d7ea6150095eeee1a91932`
- 정확한 5목·장목·3·3 규칙과 신경망 입력 형식을 유지했다. 탐색 캐시는 의미 변경에 맞춰 `node-v13`으로 분리했다.

[후보3의 핵심 8판](k4-core8-candidate3-20261030.md)에서 I5·J6는 같은 중간 국면으로 합쳐졌다. 이 공통 국면을 원인 진단에 사용했으며 두 개장의 최종 대국을 대신한 것으로 세지 않는다.

## 확인한 누락과 제한 대조

실제 기보의 15수 직전 흑 I4 후보에 저장돼 있던 백의 반증은 예상 수순만 읽어 판단하지 않았다. 독립 규칙 검증기가 전체 증명 트리의 619개 노드와 617개 방어 응수를 확인했고 보드 복원도 통과했다. **이 증거는 해당 I4 후보의 패배를 증명한다.** 실제 선택 I8의 안전성이나 최초 패착을 증명하지 않는다.

별도의 얕은 탐색 경계에서는 백 I8의 연속 4목 후보가 예비 후보 제한 전에 누락됐다. I8만 추가한 완료 대조의 점수는 기존과 같은 `-581.6053916549655`였다. I8·I9 뒤에는 J7의 연속 3목 후보도 누락돼 있었다. 두 생성 경계를 함께 보완한 완료 대조에서는 같은 잎의 백 점수가 `9,999,988`로 바뀌었다.

따라서 I8 하나의 누락으로 설명을 끝내지 않았다. 이 제한 대조는 두 후보의 연결을 놓친 원인을 뒷받침한다. 좌표 삽입은 진단에만 사용했고 생산 정책에는 좌표별 예외를 넣지 않았다.

후보4의 일반 정책은 기존 공격·차단·겸용 후보의 순서를 보존하면서, 예비 후보 제한 전에 다음을 함께 남긴다.

- 합법적인 실제 4목 후보 전체: 연속형과 끊어진 형태를 모두 포함한다.
- 최대 한 개의 연속 3목 후보: 기하학적으로 양 끝이 열려 있고 합법적인 후속 4목과 적어도 한 개의 합법적인 정확한 5목 끝점이 있어야 한다.

두 번째 항목은 후보 보존 조건이며 강제승 증거가 아니다. 점수 가산이나 돌 색에 따른 고정 성향을 추가하지 않았고, 공유 확장 예산·필수 차단·준비 자원의 사용 규칙도 유지했다.

일반 정책의 제한 탐색에서는 백 잎 점수 `9,999,986`을 얻었다. 같은 11수 국면에서 M2·H6를 완료 깊이 5로 비교한 흑 점수는 둘 다 `-9,999,986`이었다. 이는 제한된 후보와 깊이에서 얻은 평가다. 부모 국면의 모든 방어를 포괄한 패배 증명, 최초 패착의 확정, 안전한 대안의 발견으로 표시하지 않는다.

## 통과한 검사와 전체 검사 실패

작은 생성 국면에서 전체 방어 증명, 회전·반사·색 교환, 신경망 유무, 합법성·보드 복원을 검사했다. 변경된 후보 생성과 맞지 않던 시험 관측자 네 곳은 기준 후보3과 후보4에서 각각 실제 대조를 통과한 뒤 수정했다. 독립 규칙으로 실제 4목·연속 3목 후보의 합집합을 확인하고 증명 트리와 기존 자원·캐시 조건을 유지하는 검사로 바꿨다. 엔진의 판단 기준을 시험에 맞춰 낮추지 않았다.

원래 34수 국면을 별도로 실행했을 때에는 기준 후보3과 후보4에 반영한 Reader 시제품은 각각 기본 `analyze(1, 1500)` 호출로 깊이 1과 24개 후보 비교를 완료했다. 두 호출은 같은 프로세스에서 순서대로 실행했으므로 이 결과로 속도 향상 비율이나 전체 검사 통과를 주장하지 않는다.

세 번째 전체 검사에서는 `test/reader/test.cjs:81`의 같은 1,500ms 국면이 `assert(r.depth >= 1)`을 통과하지 못했다. 전체 흐름에서는 첫 비교 깊이를 완료하지 못한 결과다. **필수 완료 깊이의 실제 미달**로 기록하고 원래 시험 조건을 유지했다. JIT·GC 등 원인은 측정하지 않아 확정할 수 없다.

전체 기능 77개 통과를 확보하지 못했고 이후 브라우저 368단계 검사와 신경망 평가 일치 검사에도 진입하지 않았다. 후보4의 핵심 8판·24판은 모두 미실행이다. 기존 22승의 개별 보존이나 I4·K6의 최종 전환도 아직 확인하지 못했다.
