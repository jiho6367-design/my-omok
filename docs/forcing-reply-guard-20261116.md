# 강제 차단 뒤 반격 검사 · v5.18.66

내 4를 상대가 막는 수가 상대의 새 3이나 4를 만들면, 그 이후의 준비 공격과 반격 4까지 같은 시간 예산 안에서 우선 검사합니다. 상대가 모든 합법 방어에 이기는 증명을 완성했을 때만 해당 후보를 제외합니다. 기존 무적수 정석·검증 후속·동등 5수 선택은 유지합니다.

## 확인한 현상

기존 v5.18.65의 직접 설정 10초 재생에서, 확인한 중반 국면의 후공 34 J10 추천을 재현했습니다. J10은 실제 4이며, 선공의 35 J12는 강제 차단입니다. 하지만 이 차단으로 선공의 I12–J12–K12 열린3이 생기고, 기존 F9–H11–I12의 띈3도 남습니다. 내 공격을 계속하는 과정에서 상대에게 새 공격축을 내준 사례입니다.

이 정확한 국면에서 34 J10 뒤 35 J12부터 후공의 합법 36수 190개 모두를 포함하는 선공 승리 전략을 검증했습니다. 별도의 규칙 검사기와 기하학 검사기로 재생하고, 양색·8대칭에서도 확인했습니다. 이 결과는 해당 착수의 반증이며, 앞선 국면 전체의 필패를 뜻하지 않습니다. 전체 대국과 개인 분석 원본은 로컬에 보존합니다.

30 K11은 상대의 즉시 5목을 막는 필수 방어입니다. 이를 연속 4에 포함하면 잘못된 분석이 됩니다. 앞선 32수의 전체 패착 여부와 직접 방어 대안 G10의 안전은 아직 미확정입니다. 기보의 32수와 현재 엔진의 재생 추천도 달라, 중반 이후 모든 수가 같은 조건에서 재현됐다고 확대하지 않습니다.

## 검사 조건과 순서

후보를 둔 판에서 다음 조건을 모두 만족하면 준비 반격 검사를 먼저 배정합니다.

1. 이미 정확한 5목으로 끝난 판이 아닙니다.
2. 내 다음 정확한 5목 지점이 하나이고, 상대에게 즉시 이기는 다른 수가 없습니다.
3. 그 지점을 막는 상대 수가 현재 규칙에서 합법입니다.
4. 그 차단수 자체가 상대의 3이나 4를 만듭니다.

이 조건의 준비 반격은 최대 39수·준비수 3회 범위로 검사합니다. 기존의 연속 4 검사를 먼저 수행한 뒤, 해당 준비 검사를 금수 유도 검사보다 앞에 배정합니다. 다른 국면은 기존 25수 준비 반격 범위와 검사 순서를 유지합니다. 직렬 분석과 병렬 최종 검사 모두 같은 조건을 사용합니다.

추가 시간은 부여하지 않습니다. 후보별로 이미 정한 종료 시각과 전체 분석 종료 시각 안에서 남은 시간만 사용합니다. 넓은 증명 범위를 선택해도 실제로 검사할 수 있는 양은 남은 시간에 따라 달라집니다. 판세 점수 계산이나 일반 비교 탐색의 깊이, 신경망 가중치는 이 조건 판정으로 바꾸지 않습니다.

## 후보 제외와 미완료의 구분

3·4가 생기는 도형은 검사 대상을 고르는 근거입니다. 도형만으로 착수를 패착으로 확정하거나 다른 수를 안전한 수로 올리지 않습니다. 실제 상대 승리 증명에는 모든 합법 방어와 역공 4가 포함돼야 합니다. 시간이 끝났거나 증명을 찾지 못한 검사는 미확정으로 남깁니다.

즉시 이기는 수와 승리가 증명된 4는 유지합니다. 양끝이 열린 이기는 4, 강제 차단이 상대의 3을 만들어도 내 승리로 이어지는 4, 금수 때문에 상대가 막을 수 없는 수를 각각 구분합니다. 상대의 강제 차단을 활용한 합법적 공격 기회를 일괄 제외하지 않습니다.

## 검증 범위

공개 회귀 검사는 작은 생성판을 사용합니다. 강제 차단이 두 번째 공격축을 만드는 예를 양색·8대칭으로 검사하고, 반환된 승리 증명을 독립 규칙 검사기로 모든 응수에 대해 다시 재생합니다. 조용한 수, 새 공격을 만들지 않는 차단, 양끝이 열린 4, 이미 끝난 5목, 상대의 즉시 승리, 금수인 차단은 별도 대조군입니다. 이기는 4의 보존, 검사 미완료와 완전한 반증 미발견의 후보 유지, 공용 시간 예산도 함께 확인합니다.

수정 전후 실행본을 고정하고 같은 입력·16개 논리 프로세서·채택 모델·직접 설정 10초·실제 앱 Worker 경로로 일곱 국면을 각각 다시 분석했습니다. 자동 재시작 없이 반환을 완료했고, 추천과 표시 수순은 현재 규칙에서 합법이었습니다. 이는 원래 기보의 각 국면을 따로 비교한 결과이며, 새 추천을 이어 둔 완주 대국은 아닙니다.
