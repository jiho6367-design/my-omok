# v5.18.25 · 사월·구월·한성·항성 후속 보강

자료가 적었던 사월(I11)·구월(D9)·한성(D1)·항성(I3)의 원자료 후속을 추가하고, 미등록 초반 응수에는 공개 엔진으로 따로 분석한 대응수를 연결한다. 선공의 돌 색과 기보 따라두기 체크에 관계없이 적용한다. 판 위 주형 선택에도 저장된 후속이 표시된다.

## 원자료 후속

기존 31,975개 참고 착수의 순서·좌표·출처와 기존 추천을 보존하고 2,774개를 추가해 총 34,749개가 된다.

| 주형 | 추가 참고 착수 |
| --- | ---: |
| 사월 | 44 |
| 구월 | 2,381 |
| 한성 | 27 |
| 항성 | 322 |

[대만 원배포 자료실](https://587.renju.org.tw/program.htm)의 한성·항성 라이브러리와 [RenLib](https://www.renju.se/renlib/) 전체 주형 자료에서 아직 등록되지 않은 깊은 후속을 조사했다. 구월은 기존 등록 9수와 정확히 같은 색의 돌 배치로 전환되는 화월·계월·신월 원배포 자료의 후속을 대조했다. 원저자의 [한성](https://www.ljrenju.com/croom/d01/d01.htm)·[구월](https://www.ljrenju.com/croom/d09/d09.htm)·[항성](https://www.ljrenju.com/croom/i03/i03.htm)·[사월](https://www.ljrenju.com/croom/i11/i11.htm) 설명도 확인했다.

앱의 규칙으로 전체 경로가 합법이며 원자료에서 자기 수가 하나로 확인되고 기존 선택을 따라 연결되는 후속을 선별했다. 구월은 새로 연결되는 11수 응수를 우선하고, 그 뒤 13~25수는 차례별 최대 200개의 연결된 가지를 추가했다. 이는 공간상 중앙에 가까운 경로를 우선해 깊이와 크기를 조절한 참고 자료이며 수의 강도를 순위로 매긴 것이 아니다. 원배포 전체를 수록하거나 모든 후속을 지원한다는 뜻은 아니다. 일부 한성은 35수, 사월은 39수까지 연결된다.

기존 31,975개 수순의 추천을 대조해 보존한다. 새 참고의 양색·8대칭 조회 44,384개와 전체 경로 합법성, 출처 배치 전환을 검사한다. 원자료 라이브러리·주석·영상·개인 자료는 배포하지 않으며 원본 해시와 사실 좌표의 출처 정보를 유지한다.

## 엔진으로 보강하는 응수

기준은 배포된 v5.18.23의 공개 소스와 당시 채택 모델이다. 미채택 실험 엔진을 계산이나 배포에 섞지 않는다. 주형별 다음 두 범위를 고정해 원자료 밖 국면을 계산한다.

| 주형 | 기본 3수 뒤 미등록 상대 4수 | 대표 5수 뒤 미등록 상대 6수 | 대표 5수까지의 좌표 |
| --- | ---: | ---: | --- |
| 한성 | 218 | 204 | H8 H9 H10 G8 I9 |
| 구월 | 219 | 218 | H8 H9 I7 G8 G9 |
| 항성 | 218 | 151 | H8 I9 J8 H7 I7 |
| 사월 | 214 | 219 | H8 I9 G7 J9 G9 |

새 계산 대상은 1,661개이며 회전·반사로 같은 판을 묶으면 1,352개다. 각 국면은 기보를 끈 심층 분석에 15초 예산을 주어 대응수를 비교하고, 선택한 수 뒤에는 상대 입장에서 별도의 750ms 분석을 수행한다. 예산보다 일찍 비교나 승리 수순 확인이 완료될 수 있으며 실제 시간·완료 깊이·소스 commit·모델 식별자·원본 결과 해시를 별도로 기록한다. 완료된 비교도 독립적으로 확인한 승리 수순도 없거나, 패배·상대의 강제승 반격이 확인된 결과는 등록하지 않는다.

승리 수순을 찾아 일찍 끝난 분석은 비교 완료로 바꾸지 않는다. 별도의 규칙 검사기로 상대의 모든 합법 응수와 승리 수순을 재검사한 경우에만 오프라인 검증 여부와 증거 해시를 기록한다. 이 경우도 저장된 대응수 조회 자체를 현재의 승리 증명으로 표시하지 않는다.

한 수만 추가하고 다시 끊기는 경우를 줄이기 위해, 위 대응수 뒤 상대 분석의 1순위 응수에 대한 다음 자기 수도 자료 밖이면 3초 예산으로 새로 계산한다. 각 후속에도 750ms 상대 분석을 별도로 수행한다. 이는 상대의 모든 다음 응수를 전수 지원하는 범위가 아니라 계산된 대표 반격 한 갈래의 7·9수 연결이다. 예산을 다 쓴 경우에는 마지막으로 비교가 완료된 깊이만 기록하며 15초 분석과 같은 노력이나 승리 증명으로 표시하지 않는다. 이 3초는 사전 계산의 예산으로, 앱에서 기능을 켜는 조건이 아니다.

최종 저장 대응은 2,884항목이다. 기본 대응 1,661항목과 후속 1,223항목이며, 회전·반사 중복을 제외하고 실제로 분석한 국면은 각각 1,352개와 1,115개다. 모든 원본 해시·수순·예산·모델·좌표 변환을 대조했다. 원결과에 승리가 있는 278개는 합법 상대 응수 60,276개 분기를 별도로 검증했다. 이전 비교 결과의 깊이가 현재 결과와 다른 157건은 비교 완료로 옮기지 않았으며, 오프라인 검증 정보와 현재 조회 결과를 구분한다.

원자료를 먼저 조회하고 자료 밖의 정확한 등록 국면에서만 엔진 사전분석을 사용한다. 회전·반사와 양색을 지원하고, 즉시 승리·필수 차단·확인된 반증을 우선한다. 명시적인 심층 분석은 저장된 결과 대신 새로 탐색한다. 저장된 예산을 초과하는 수동 분석도 새로 탐색한다. 다른 응수나 등록되지 않은 후속에서는 기존 엔진을 사용한다.

자료 증가로 최초 조회가 늦어지지 않도록, 실행 중에는 현재 판과 같은 색 배치로 일치할 수 있는 출처 수순을 먼저 선별해 준비한다. 선별된 수순은 이후의 착수까지 전체 합법성을 검사한다. 모든 대안·우선 선택·출처 충돌을 보존하며 다른 판에는 그 국면용 인덱스를 재사용하지 않는다. 전체 자료를 검사하는 컴파일러도 별도로 유지해 동일한 추천·선택지와 오류 경계를 대조한다.

참고 수순과 사전분석은 강제승·무패·전역 최선의 증명이 아니다. 사전분석의 깊이·점수·노드를 현재 탐색의 성과로 표시하지 않으며 화면에는 주형 이름과 `엔진 사전분석 대응`을 구분해 표시한다. 기존 포월 174개 결과는 원래 바이트를 보존한다.

## 검증

`test/opening-four-sources.cjs`는 원자료 전체 경로와 대칭 조회, 기존 자료 해시, 출처 전환, 각 주형의 실제 깊은 수순을 검사한다. `test/opening-continuations.cjs`는 정확한 돌 배치·양색·대칭·주형 이름·충돌·금수·종료·자료 우선·심층 전환·증거 불변성과 승리 증명 오표시 방지를 검사한다. 기존 정석·포월 사전분석·판 위 선택 검사를 함께 유지한다. `test/opening-four-sources-ui.cjs`·`test/opening-continuations-ui.cjs`와 기존 브라우저 검사로 실제 HTML의 조회·선택·무르기·심층 Worker·모바일 표시를 확인한다.

현재 판 전용 조회는 등록된 34,703개 돌 배치에서 전체 컴파일과 추천 객체·선택지 전체가 동일했다. 새 대응 2,884항목의 양색·8대칭 조회 46,144개도 검사했다. 실제 공개 엔진·채택 모델로 네 주형의 모든 상대 4수 888개와 대표 5수 뒤 모든 상대 6수 880개를 자동 15초 설정에서 조회했다. 합계 1,768곳 모두 합법적인 대응이 즉시 연결됐으며, 원자료 110곳을 우선하고 나머지 1,658곳은 사전분석 대응을 사용했다.

공개 `dist/index.html`과 이 PC의 개인 외형 `outputs/omok.html`은 같은 공개 엔진으로 빌드한다. 개인 외형·기보·저장 키·기존 채택 모델과 별도 미완성 실험은 보존한다.
