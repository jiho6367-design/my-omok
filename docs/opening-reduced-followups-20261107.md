# v5.18.31 · 큰 사각형 환원 뒤의 실제 판 사전분석

중앙 첫 돌 뒤 상대가 5×5 바깥 테두리16칸에 둔 경우, 기존64개3수 선택지에서 이어지는 실제 판의 후속 대응을 보강한다. 기보 따라두기 체크 없이 자동 최대15초 모드에 적용하며, 등록된 응수는 새 탐색을 기다리지 않고 조회한다. 원자료가 없는 판은 현재 배포 엔진과 기존 내장 모델을 고정해 직접 분석했다.

## 지원 범위

회전·반사로 같은 배치를 묶으면9개 대표3수 배치다. 각각 상대의 합법적인4수222개를 조사했다. 대표1,998개 중 기존 원자료70개, 기존 정확한 판 사전분석34개, 새 분석 대상1,894개로 나뉜다. 전체16칸·64개 선택지로 펼치면 상대4수14,208가지 중 기존 자료740가지와 새 대상13,468가지다. 같은 판이 다른 착수 순서로 만들어진 중복은 별도로 식별했다.

| 후속 | 보강 범위 |
| --- | --- |
| 5수 | 새 분석1,894개. 기존 자료와 합쳐 대표1,998개 합법4수 전체에 대응 |
| 7수 | 새 분석1,802개. 주형별 대표5수 하나씩에서 합법6수1,980개 전체에 대응 |
| 9수 이후 | 26개 선택 진행을15수까지 연결. 새9수13개·11수19개·13수18개·15수21개 |
| 새 등록 항목 | **3,767개** · 같은 실제 판의 회전·반사 및 착수 순서 별칭을 포함 |

대상 주형은 잔월·금성·송월·구월·신월·수월·포월·은월·사월이다. 7수 전수 범위는 각 대표3수 배치에서 선택한 상대4수와 실제 추천5수를 거친 국면을 기준으로 한다. 모든 가능한5수에서의 상대6수 전체를 수록한다는 뜻은 아니다. 9수 이후는 선택한 재응수의 후속이며, 정확한 수순과 수량은 공개 검사 자료에 기록한다.

## 실제 판과 분석 근거

기존 원자료의 좌표를 옮겨 읽는 기능과 새 엔진 사전분석은 구분한다. 새 분석은 옮겨진 돌을 모두 포함한 실제15×15 판에서 정확한5목·양쪽33금지 규칙으로 실행했다. 기존 중앙 주형의 탐색 점수·깊이·승리 증명을 평행 이동해 쓰지 않는다.

새 결과는 별도 `opening-reduction-data.js`에 저장한다. 원래의 전체 착수, 실제 판 식별 해시, 결과 해시, 실행 소스·모델 식별자와 회전·반사 번호를 보존한다. 같은 실제 판을 만드는 여러 착수 순서는 고정된 대표 결과로 일치시킨다. 원본 판 전체와 등록 판 전체, 추천수가 같은 회전·반사로 정확히 일치하는지를 다시 검사한다. 가장자리까지 이동하는 평행 이동은 허용하지 않는다.

일반 분석은 국면당3초, 선택한 수 뒤의 상대 확인은750ms를 배정했다. 13개 결과는 상대의 모든 합법 응수에 대한 승리 증명을 독립적으로 재검증했다. 그중1개는 원래 결과를 보존한 채5초 상한의 별도 인증으로 보완했다. 이 증명도 조회 시 현재 탐색의 승리 판정으로 넘기지 않는다.

완료된 제한 탐색의 후보 비교 또는 독립 검증한 승리 증명이 있는 결과만 등록한다. 제한된 상대 역공 검사에서 반증이 발견되거나, 비교 미완료·시간 초과·불법 수순이면 채택하지 않고 재분석한다. 역공 검사를 통과했다는 사실은 모든 미래 응수에서 안전하다는 증명이 아니다. 후보 비교는 정해진 탐색 후보·깊이 범위에 관한 결과다.

조회 시에는 현재 판 전체의 돌 색과 위치를 정확히 맞춘다. 등록된 과거 분석의 깊이·노드·증명 정보는 과거 분석 근거로만 표시한다. 현재 탐색의 깊이·점수·승리 증명으로 승격하지 않는다. 색과 선공 역할은 구분하며, 흑·백 어느 색으로 선공을 선택해도 같은 역할 기준을 쓴다.

## 기존 동작과 우선순위

즉시 승리·필수 방어와 유효한 기존 정석의 우선순위를 유지한다. 새 추천도 반투명 돌·주형 이름과 선택 목록에 표시한다. 실제 상대 착수 뒤 현재 판에서 조회한 환원 사전분석은 예상 응수의 일반 사전 계산보다 먼저 확인한다.

기존 원자료61,441개·중앙 주형 후속 사전분석31,779개·별도 포월174개 응수와 내장 채택 모델은 그대로 유지한다. 새 실제 판 사전분석은 완전한 판 일치로 조회하므로, 착수 순서를 옮겨 읽는 원자료의 기보 조건과 구분한다. 일부 기록이 없거나 PASS가 섞여 원자료 환원을 사용할 수 없어도, 현재 판 전체가 실제 분석 자료와 같으면 그 정확한 판 결과를 조회할 수 있다.

자료에 없는 국면은 일반 분석으로 이어진다. 명시적으로 심층 분석을 선택하거나 저장된 분석보다 긴 사용자 지정 시간을 요청하면 새 탐색을 수행한다. 자동15초 설정은 저장 분석의 시간보다 길다는 이유만으로 정석 조회를 생략하지 않는다.

## 검증과 배포

관련 단위·빌드 검사25개와 공개 실행본 화면 검사15개를 통과했다. 생성 fixture는9개 환원 주형·양쪽 색·8방향에서 실제 판 일치와 잘못된 출처·변환·기보를 검사한다. 실제 등록3,767개는 양쪽 색·8방향60,272회 조회와 전체 합법 수순·원판 근거를 대조했고, 대표4수1,998개와 대표5수 뒤6수1,980개에서 실제 자동 추천을 확인했다. 선택26가지의5·7·9·11·13·15수 부모 추천도 실제 정책과 일치한다.

새 대응의 화면 검사는768개 국면과 반투명 돌·선택 목록 클릭·되돌리기·현재 판 우선순위·모바일390px를 확인했다. 이 공개 빌드 검사에서 추천 표시 최대80ms, 화면 오류0이었다. 자료 밖 응수는 선택지를 숨기고 일반 Worker 분석을 시작하며, 명시적인 심층 분석도 새 Worker를 사용함을 검사했다. 개인 실행 경로의 별도 배포·화면 검사 기록을 확인한 뒤 공개 동기화를 완료한다.

공개 실행본은 흑백 돌의 `dist/index.html`이다. 개인 실행본 두 경로는 기존 외형·저장 키·기보와 내장 모델을 보존한 동일 빌드로 배포한다. 이번 보강은 엔진·정석 유지보수이며 새 학습 모델의 채택이 아니다.
