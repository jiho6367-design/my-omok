# v5.18.23 · 판 위에서 주형 수순 선택

선공인 내 차례에 현재 판에서 이어지는 저장 주형 수순을 반투명 돌과 이름으로 표시한다. 판 위 돌이나 아래 목록의 주형·좌표를 누르면 그 위치에 착수한다. 기본 추천과 다른 수순도 직접 선택할 수 있다.

3수에서는 상대 2수에 맞는 유리한 주형을 제시한다. 인접한 가로·세로 2수에는 화월·잔월 등 11주형, 대각선 2수에는 포월·운월 등 10주형이 해당한다. 거울 위치를 포함해 각 판에서 선택 위치 19개가 나온다. 기존 제외 주형 5개는 표시하지 않는다.

그 이후에는 정확한 현재 판과 일치하는 등록 후속만 표시한다. 5·7·9수 이후에도 자료가 있는 범위에서 이어지며 일부는 39수까지 있다. 기존 포월 174개 사전분석 대응도 저장된 해당 국면에서 선택할 수 있다. 자료가 없거나 조회 범위를 지나면 주형 선택을 숨기고 기존 분석을 사용한다.

표시 이름은 저장된 후속 수순의 주형이다. 같은 돌 배치로 옮겨가는 다른 주형 수순도 포함한다. 예를 들어 화월로 시작한 판에서도 같은 배치의 사월 자료가 연결될 수 있다. 한 위치에 여러 주형 자료가 겹치면 판에는 대표 이름, 툴팁·접근성 이름·아래 목록에는 전체 이름을 표시한다. 현재 첫 세 돌의 주형을 새로 바꿔 판정하는 기능은 아니다.

선택지는 기보 따라두기 체크와 관계없이 표시하며, 추천 표시를 끄면 함께 숨긴다. 선택 후에는 상대 차례가 되어 사라지고, 다음 내 차례에 새로운 후속을 표시한다. 무르기로 해당 국면에 돌아오면 다시 표시한다. 복기·종료·상대 차례에는 표시하지 않으며 일시 정지 중에는 선택 버튼도 멈춘다. 금수·점유 칸·즉시 방어를 놓치는 수와 확인된 반증 후보는 제외한다.

기존 기본 추천과 원자료·174개 사전분석 결과는 보존한다. 이 변경은 저장된 참고 수순의 선택 기능이며 새로운 승리 증명이나 학습 모델 채택이 아니다.

검증은 `test/opening-choices.cjs`의 양색·8대칭, 실제 3·5·7·9수·조건부 국면·미등록 국면·조회 상한·필수 방어 검사와 `test/opening-choices-ui.cjs`의 실제 판 클릭·목록 키보드 선택·무르기·표시 숨김·모바일 검사로 구성한다. 실제 사용자 HTML에서 동일 기능과 최초 표시 시간, 개인 외형·기보·채택 모델 보존도 확인한다.
