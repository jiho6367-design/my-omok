# 후공 방어·역공 수읽기 보강 · v5.18.32

자동 최대 15초의 일반 수읽기에서 상대의 준비 공격과 실제 필수 차단 뒤의 후속을 더 읽는다. 기보 따라두기 체크와 관계없이 적용하며 3초 활성 조건을 두지 않는다. 선공·후공 역할과 돌 색을 구분하고, 양쪽에 같은 탐색 규칙을 적용한다.

이번 변경은 모든 방어 가능한 국면을 해결하는 필승방어 증명이 아니다. 실제 국면의 전 합법 응수를 검증한 공격 수순이 있을 때만 승리를 확정한다. 제한 탐색이 끝나도 반증이나 승리 증명이 없으면 미해결로 남긴다.

## 달라진 수읽기

이전의 짧은 말단 탐색은 한쪽의 준비 수 뒤 상대가 별도로 준비하거나, 실제 강제 차단을 마친 뒤 다른 축으로 공격하는 변화를 충분히 이어 읽지 못할 수 있었다.

- 양쪽에 각각 준비 수와 실제 유일 방어 뒤 한 번의 준비 재개 기회를 둔다. 실제 강제 차단은 선택 연장 횟수를 쓰지 않는다.
- 기존 공격·차단 대표를 보존하면서 실제 합법 4, 상대의 열린 4가 되는 양쪽 차단점, 유효한 연속 3 후보를 함께 읽는다. 준비 기회를 쓴 뒤의 추가 4 후보는 상위 두 개 한정이다.
- 각 완료 깊이의 모든 후보와 직렬·병렬 비교가 같은 선택 지평을 쓴다. 첫 깊이부터 양쪽 준비를 읽고, 다음 완료 깊이에서 지평을 넓힌다. 앞선 후보의 작업량이나 남은 시간 때문에 같은 하위 문제의 의미를 바꾸지 않는다.
- 판·차례·깊이·남은 연장·준비 권한·루트와의 거리가 같은 로컬 탐색 결과만 재사용한다. 이전 엔진의 저장 결과와 새 지평의 저장 결과도 구분한다.

후보 계산은 원래 대표와 실제 위협을 그대로 보존하는 한정 캐시로 줄였다. 캐시 사용 여부에 따른 값·합법성·판 복원은 작은 생성 국면으로 따로 확인했다.

## 닫힌 준비 공격의 별도 검증

열린 3이나 4로 바로 보이지 않아도 여러 축의 합법 연결을 준비하는 후보를 일반 비교와 별도로 검사한다. 축 수가 같은 후보의 기존 정적 평가는 검사 순서에만 쓰며, 승리·안전 판정으로 올리지 않는다.

독립 준비 검사와 기존 선택 후보 검사는 각각 정해진 한정 예산을 갖고 같은 절대 착수 시간 안에서 실행한다. 앞선 검사가 시간 초과됐다는 이유로 나중에 실제 선택된 후보의 원래 검증 기회를 없애지 않는다. 큰 유한 승리 예상값을 받아도 실제 닫힌 준비 모양이면 충분한 준비 검증 예산을 사용한다.

후보 지명이나 한 개의 예시 수순만으로 승리를 표시하지 않는다. 검증 결과에는 현재 전체 판, 실제 차례, 모든 합법 방어점과 그 후속이 연결돼야 한다.

## 확인한 범위

병합 전 동일한 기존 채택 모델과 자동 최대 15초 설정으로, **9개 입력 국면에서 만든 회전·반사·색교환 변형 60개**를 비교했다. 독립적인 60개 대국이나 승률 측정이 아니다.

| 항목 | 이전 엔진 | 개선 후보 |
| --- | ---: | ---: |
| 완전한 승리 증명을 얻은 변형 국면 | 18 | 34 |
| 기존 18개 증명 유지 | — | 18 |
| 새로 승리를 증명한 변형 국면 | — | 16 |

새 16개는 한 생성 역공 국면의 양쪽 색·8방향 변형이다. 해당 국면에서 선택한 수 뒤 합법 방어 197개를 모두 별도 규칙·증명 검증기로 확인했다. 원래 증명하던 다른 생성 국면의 16개 변형에서는 201개 방어를 확인해, 준비 검사 예산을 나누는 과정에서 기존 증명을 놓친 회귀를 수정했다.

이전 엔진이 고른 G6의 패배는 입증하지 않았다. 새로운 수의 완전한 승리 증명을 얻은 결과와 이전 수의 패배를 증명하는 결과는 구분한다. 나머지 미해결 국면을 안전하거나 패배라고 확대하지 않는다.

후보 단계에서는 관련 검사 40개와 실제 브라우저·Worker의 16개 조건을 확인했다. 브라우저 조건은 두 생성 국면 × 양쪽 색 × 두 회전 × 직렬/병렬 실행이며, 기보 따라두기를 끈 상태다. 화면이 받은 증명 자체를 독립 검증하고 오류와 남은 Worker가 없는지 확인했다. v5.18.31 자료와 병합한 최종 v5.18.32 소스에서도 관련 검사 40개를 모두 다시 통과했다. 같은 통합 공개 HTML의 두 생성 국면 × 양쪽 색 × 직렬/병렬 8개 조건을 실제 브라우저에서 재검증했고, 3,767개 환원 후속의 60,272개 실제 판 조회도 다시 통과했다. 사용자의 개인 실행 파일 배포와 확인은 별도 최종 릴리스 절차로 수행한다.
