# v5.18.28 · 9수 이후 후속 응수

유리한 21주형의 실제 추천으로 이어지는 9수 국면을 기준으로 11수 이후 후속을 보강한다. 기존 초반 선택과 원자료·사전분석 기록은 보존한다. 선공 역할의 돌 색과 기보 따라두기 체크에 관계없이 자동 모드에서 조회하며, 저장된 다음 수는 반투명 주형 선택에도 표시한다.

한성·항성·사월에서는 기존 추천을 보존하면서 추가할 새 고유 원자료를 확보하지 못했다. 이 주형의 자료 밖 국면은 아래 엔진 분석과 구분한다. 원자료의 좌표는 현재 앱 규칙의 필승 증명이 아니며, 라이브러리·주석·도표·영상은 배포하지 않는다.

기존 원자료의 추천으로 이어지는 9수 부모 7,975개를 선별해 조사했다. 일반 선별은 주형별 최대 500개를 7수 부모별로 나누어 고르고, 엔진 분석 대상인 대표 9수와 배치가 같은 원자료 부모를 우선했다. 이 과정에서 수월의 부모 하나를 추가했다. 새 11수는 주형별 최대 160개, 13·15수는 각 80개, 17~39수는 각 25개를 골랐다. 이는 연결 범위를 고르는 기준이며 수의 강도 순위가 아니다. 전체 자료의 모든 변화나 모든 9수 부모를 수록한 것은 아니다.

기존 49,583개 사실 좌표·메타데이터·추천과 충돌 224개를 보존했다. 새 사실은 16개 원본 LIB의 해시·실제 바이트 오프셋·전체 원본 경로와 7,302개 모두 대조했다. 양색·8대칭 116,832조회와 연결 부모 37,037개를 확인했고, 불법·이미 종료된 경로와 불명확하거나 기존 추천을 바꾸는 국면은 추가하지 않았다.


## 자료 밖 국면의 엔진 분석

공개 v5.18.27의 commit 05417cb98ec75beed07ed9084eaec2a6b67ca625와 기존 채택 모델을 고정하고, 정석 조회와 저장 기보를 끈 상태에서 대응수를 계산했다. 개인 실험 엔진과 개인 승리 기보는 계산 기준에 섞지 않는다.

21주형에서 기존 대표 5수와 현재 기본 추천인 7·9수로 실제 이어지는 대표 9수를 하나씩 고정했다. 대칭 국면의 후속 좌표 수를 이용한 근사 원자료 밀도로 후보를 정렬하고, 원자료·가까운 상대 수·좌표 순서를 함께 고려했다. 이 밀도는 대상 9수를 고르는 휴리스틱이며 실제 11수 지원 수나 기력 순위는 아니다. 실제 응수 지원 수는 아래 고정 국면별 검사값을 사용한다. 모든 9수 변화를 조사한 결과는 아니다.

이 대표 9수 뒤의 합법 상대 10수는 총 4,535개다. 기존 원자료 300개, 즉시 5목 완성 429개, 필수 차단 6개를 유지하고, 빈 3,800국면에 15초 예산으로 새 11수를 계산했다. 각 계산 뒤 상대에게 750ms 예산으로 반격을 별도로 분석했다.

협월은 이 대표 국면의 11수가 이미 즉시 전술과 원자료로 전부 처리되므로 새 11수 분석을 중복 등록하지 않는다. 이미 11수에 5목이 완성되는 429국면은 대국을 종료한다. 나머지 새 11수 3,800개와 기존의 비종료 원자료·차단 306개에서 선택된 상대 12수 한 갈래씩, 총 4,106개 연결을 조사했다. 이 연결 중 자료·즉시 전술로 처리되는 973개는 유지하고, 빈 곳의 13수를 3초 예산으로 계산해 3,133개를 등록했다. 회전·반사로 같은 판이 되는 중복을 제외한 새 13수 계산은 3,132개다. 이후 상대 반격에도 750ms 예산을 적용했다. 모든 합법 상대 12수나 모든 미래 방어를 조사했다는 뜻은 아니다.

그 뒤 현재 추천으로 연결되는 계산 13수 후보와 이미 기록된 상대 14수를 조사해, 주형별 최대 하나의 새 15수 대응을 추가했다. 새 15수 19개를 등록하고 원자료·즉시 전술·종료 국면은 구분했다. 이 범위는 전체 15수 응수의 완전 지원을 뜻하지 않는다.

새 사전분석 응수는 총 6,952개이며 기존 15,241개와 합쳐 22,193개다. 기존 분석 정보·확장 기록·증거 해시와 처음 포월 174개 분석 파일을 보존한다. 저장 상한은 32,768개로 높였고, 등록 주형은 기존의 유리한 21주형으로 제한한다.

승리 표시가 있지만 증명 본문이 빠진 원결과는 수정하지 않는다. 최대 5초 한도로 별도 전체 응수 증명을 확보하고 원본 해시·판·착수·소스·모델에 연결해 독립 재생을 통과한 경우만 등록한다. 보완 증명 시간은 기존 3초·15초 분석 시간과 구분하며, 실제 앱에서 기다리는 조건으로 사용하지 않는다.


사전 계산은 현재 선택 수·완료 깊이·비교 출처가 일치하는 완료 비교 또는 별도 규칙 검사로 확인한 승리 수순만 등록한다. 원결과에 승리 증명이 있으면 비교 완료 여부와 관계없이 전체 증명을 다시 검사한다. 실제 예산·시간·깊이·노드·소스 commit·모델 식별자·결과 해시를 보존하고, 현재 수와 다른 과거 비교 정보를 완료 비교로 표시하지 않는다.

## 실제 동작과 검증

즉시 승리·필수 차단·확인된 반증과 원자료 우선순위는 유지한다. 저장 응수는 현재 판 전체의 돌 배치·차례와 정확히 일치할 때만 회전·반사를 포함해 조회한다. 자료 밖 국면은 일반 분석으로 이어진다. 엔진 사전분석 응수가 있는 국면에서 명시적 심층 분석을 선택하면 저장된 사전분석을 건너뛰어 새로 계산한다. 원자료의 기존 우선순위는 유지한다. 모든 미래 응수를 수록하거나 필승을 보장하는 기능은 아니다.

저장된 점수·깊이·노드와 승리 수순을 현재 탐색의 성과로 옮기지 않는다. 현재 조회 결과의 증명·패배 판정은 비우고, 과거 계산 정보는 사전분석 근거로 구분한다. 사전 계산의 3초 예산은 기능 활성 조건이 아니며 자동 최대 15초 모드에서 기보 체크 없이 적용한다.

공개 엔진의 자동 최대 15초·기보 체크 해제 상태에서 고정 대상 4,535국면 모두 합법 응수를 조회했다. 새 사전분석의 양색·8대칭 조회 111,232개와 선택 국면의 전체/선별 조회 동등성, 부분·변조 판 거부, 원자료·즉시 전술 우선순위와 기존 15,241개 보존을 확인했다. 새 원자료는 별도 Node 파서로 원본 경로·오프셋·해시를 다시 대조했고 7,302개 변조 경로를 거부했다.

새 사전분석의 브라우저 928국면에서 추천 표시 최대 86ms, 새 원자료 576국면에서 최대 62ms를 확인했다. 반투명 돌의 실제 클릭·무르기·기보 옵션 독립성, 양색·대칭·모바일 및 명시적 심층 분석 전환과 기존 브라우저 회귀 검사를 통과했다. 관련 정석 검사와 브라우저 11종 검사를 수행했으며, 기존 미완성 학습·탐색 실험의 검증으로 확대하지 않는다.

공개 dist/index.html과 이 PC의 실제 outputs/omok.html은 같은 검증된 공개 엔진으로 빌드한다. 기존 모델·개인 외형·브라우저 저장 키·기보와 별도 미완성 실험을 유지한다.
