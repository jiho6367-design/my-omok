# v5.18.29 · 15수와 이후 후속 응수

유리한 21주형의 15수 이후 후속 자료를 보강했다. 원자료 밖 대응은 주형별 현재 기본 추천으로 도달하는 13수 국면을 기준으로 별도 계산했다. 선공 역할의 돌 색과 기보 따라두기 체크에 관계없이 자동 모드에서 조회하며, 저장된 다음 수는 반투명 주형 선택에도 표시한다.

## 원자료 보강

원배포 RenLib 자료에서 좌표 사실 4,556개를 추가해 원자료 항목은 61,441개가 됐다. 새 항목은 전체 착수 번호 기준 15수 1,467개, 17수 1,339개, 19수 947개, 21~39수 803개다. 20주형에 새 원자료가 있으며, 한성(D1)의 새 고유 후속은 확보하지 못해 별도 엔진 분석으로 보완한다. 최대 39수까지 있는 것은 일부 가지의 범위다.

기존에 등록된 원배포 자료의 13수 경로 2,554개를 출발점으로 사용하고, 전체 26주형 라이브러리와 현재 엔진의 21개 대표 13수 국면도 따로 조사했다. 현재 대표 국면까지의 기본 추천 105개는 실제 엔진으로 확인했다. 넓은 원자료 경로 전체가 현재 엔진의 기본 추천이라는 뜻은 아니다. 즉시 승리나 필수 방어가 먼저 선택될 수 있다.

새 항목은 원본 파일의 해시·바이트 위치·전체 수순과 대조했다. 수순 순서가 다른 전환은 양쪽 수순이 모두 합법이고 차례별 돌 색을 포함한 판 전체가 같을 때만 연결했다. 원래 순서는 출처 정보에 보존했다. 불명확한 주석·서로 다른 추천·종료된 수순·기존 원자료 및 사전분석 국면과 겹치는 항목은 제외했다. 기존 원자료 56,885개와 기존 사전분석 22,193개의 원본 및 조회 결과를 유지했다.

원자료는 선공 한쪽의 합법 자식이 하나인 가지를 단계별로 선택했다. 주형별 상한은 15수 140개, 17수 80개, 19수 60개, 21~39수는 각 16개다. 이 선택 상한은 자료량을 제한하며 수의 우열이나 모든 응수 수록을 뜻하지 않는다. 일반 렌주 자료를 이 앱의 정확한 5목·양쪽 33금지 규칙에서의 필승 증명으로 표시하지 않는다.

출처는 [대만 렌주 자료 원배포](https://587.renju.org.tw/program.htm), [RenLib 저자 안내](https://www.renju.se/renlib/), [주형 이름 안내](https://renjulike.tistory.com/530)와 주형별 원저자 자료([화월 예시](https://www.ljrenju.com/croom/d04/d04.htm))를 확인했다. 원배포자는 자료의 수가 최선이 아닐 수 있다고 안내한다. 해설·도표·라이브러리 원본은 배포하지 않는다.

## 자료 밖 국면의 엔진 분석

공개 v5.18.28의 commit 9fa387c910fd982dc1b75c25a58f36254adc5264와 기존 채택 모델을 고정하고 정석 조회·저장 기보·탐색 기억을 끈 상태에서 대응수를 계산했다. 기존 모델의 평가·채택 이력은 유지하고 개인 실험 엔진과 개인 승리 기보는 계산 기준에 섞지 않는다.

각 유리한 주형에서 현재 기본 추천으로 도달하는, 아직 승부가 끝나지 않은 13수 국면을 하나씩 고정했다. 그 뒤 상대가 둘 수 있는 합법적이고 승부를 끝내지 않는 14수 4,451개를 전부 확인했다. 기존 원자료 246개·기존 사전분석 2개·필수 방어 24개를 유지하고, 나머지 4,179곳에 새 15수 대응을 계산했다. 이 범위는 모든 가능한 13수 국면을 뜻하지 않는다.

새 엔진 사전분석 응수는 9,586개다. 15수 4,179개, 17수 2,150개, 19수 3,236개, 21수 21개를 추가해 총 31,779개가 됐다. 17·19수는 앞 단계에서 선택된 상대의 재응수 뒤를 분석했으며, 21수는 종료되지 않은 19수 가지 가운데 주형별 최대 한 경로를 선택했다. 모든 상대 16·18·20수를 망라한 것은 아니다.

마지막 1곳의 60초 계산은 공개 엔진의 심층·사용자 지정 모드 시간 상한 두 곳만 25초에서 60초로 높인 별도 오프라인 실행이다. `public28-offline-cap-60k-v1` 식별자와 기준 소스·실행 소스 해시, 정확한 변경 내용·해시를 해당 결과에 연결했다. 이 상한 변경은 배포 앱의 실행 엔진에 포함하지 않는다. 미완료 표식을 지워 완료 처리한 항목은 없다.

현재 선택 수·완료 깊이·비교 출처가 일치하는 완료 비교 또는 별도 규칙 검사로 확인한 승리 수순만 등록한다. 승리 표시는 비교 완료 여부와 관계없이 모든 합법 방어를 다시 검사한다. 원결과에 증명 본문이 없으면 원본을 보존하고 별도 전체 응수 증명을 확보해 원본 해시·판·착수·소스·모델과 연결한다. 실제 시간·깊이·노드·결과 해시와 확장별 분석 예산을 보존하고, 오래된 비교 정보를 현재 비교 완료로 표시하지 않는다.

상대 20수의 제한 시간 계산 1건에는 비교 미완료 표식이 남아 있다. 해당 내 19수는 그 상대 수를 포함한 모든 합법 방어에 대한 승리 증명을 별도로 통과했다. 이 상대 수는 합법적인 선택 경로로 보존했으며, 비교 완료나 상대 최선수로 표시하지 않는다. 새 21수 표본을 고른 21개 부모에는 포함되지 않는다. 미완료인 내 추천 수를 등록한 경우와 구분한다.

## 실제 동작과 검증

즉시 승리·필수 차단·확인된 반증과 원자료 우선순위는 유지한다. 현재 판 전체의 돌 배치·차례와 정확히 일치하는 저장 국면에서만 회전·반사를 포함해 조회한다. 자료 밖 국면은 일반 분석으로 이어진다. 엔진 사전분석 응수가 있는 국면에서 명시적 심층 분석을 선택하면 저장된 사전분석을 건너뛰어 새로 계산하며, 원자료의 기존 우선순위는 유지한다.

사전 계산의 분석 예산은 기능 활성 조건이 아니다. 자동 최대 15초 모드에서는 기보 체크 없이 적용한다. 저장된 점수·깊이·노드와 승리 증명을 현재 탐색의 성과로 옮기지 않고 과거 계산 정보로 구분한다. 모든 미래 응수를 수록하거나 필승을 보장하는 기능은 아니다.

통합 정석 검사 19개를 통과했다. 새 원자료의 색상·회전·반사 조회 72,896회와 부모 연결 검사 29,815회, 새 엔진 응수 조회 153,376회, 기준 14수 전체 4,451곳 및 새 17수 이후 응수 5,407개의 실제 자동 추천을 확인했다. 새 21수는 5~19수의 실제 기본 추천 연결도 검사했다. 원자료는 별도 검토자의 원본 바이트 재파싱으로, 엔진 자료는 별도 규칙 검사·전체 합법 방어 증명·선택된 부모 수순 및 결과 해시 대조로 확인했다.

공개 빌드의 화면 검사 13개를 통과했다. 새 엔진 후속 1,344국면과 새 원자료 624국면에서 양쪽 색·8방향 변환, 반투명 돌·선택 목록, 클릭·되돌리기와 기보 체크 해제를 확인했다. 자동 조회에는 새 분석 작업이 시작되지 않으며, 사전분석 국면의 명시적 심층 분석은 새 작업을 완료했다. 모바일 폭 390px와 화면 오류 없음도 확인했다.

공개 dist/index.html과 이 PC의 실제 outputs/omok.html은 같은 검증된 공개 엔진으로 빌드한다. 개인 외형·브라우저 저장 키·기보·기존 채택 모델과 별도 미완성 실험을 유지한다. 원본 라이브러리·주석·도표·영상과 내부 분석 원본은 배포하지 않는다.
