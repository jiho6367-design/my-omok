# 닫힌 공격 준비의 승리 검증 · 2026-11-01

v5.18.13은 당장 열린 3목이나 4목이 없는 후보도 공격 준비를 확인해 승리 검증에 보낸다. 기보 좌표를 추천에 넣거나 순서대로 재생하는 변경은 아니다.

## 발견한 누락과 변경

기존 엔진은 분석 중 선택한 후보가 높은 승리 평가 또는 3목·4목 모양을 가질 때만 추가 승리 검증을 했다. 따라서 닫힌 3목과 다른 축의 연결을 함께 준비하는 수는 일반 평가에서 선택되어도 검증을 건너뛸 수 있었다. 실제 후속 승리는 기존 검증기로 확인할 수 있었지만, 그 검증기를 호출하지 않는 문제가 있었다.

새 분류기는 후보를 둔 뒤 최소 두 축에서 합법적인 정확한 5목 연결 경로가 있는지 확인한다. 그중 한 축은 이미 돌 세 개를 포함해야 한다. 각 경로의 준비 수·4목 수·마지막 5목 수에 실제 금수와 장목 규칙을 적용한다. 닫힌 3목이나 끊긴 연결도 이 조건을 만족하면 검사 대상이 된다.

이 경로는 상대가 두지 않는 가상 배치이므로 승리 근거로 사용하지 않는다. 점수나 강제수 표시를 더하지 않고 기존 검증기에 후보를 전달하는 용도로만 쓴다. 검증기는 실제 번갈아 두는 순서로 상대의 모든 합법 응수를 확인하며, 완료된 증명이 있을 때만 강제승으로 확정한다. 상대의 역공·정확한 5목·합법적인 탈출이 있거나 시간이 부족하면 확정하지 않는다.

v5.18.14부터 자동 최대 15초 모드에서는 3초 조건 없이 추가 검증을 활성화한다. 초반 등 짧게 배정된 분석에서도 기보 따라두기 체크와 관계없이 동작한다. 자동 모드 이외에는 기존 3초 조건을 유지한다. 추가 검증 예산은 전체 예산의 25%와 1.2초 중 작은 값으로 제한한다. 기존 3목·4목 검증 예산과 별도로 관리하되 전체 분석 마감 시간 안에서 실행한다. 빠르게 1초 모드의 기존 배분은 유지한다. 기존 Reader의 탐색 깊이·후보 평가·학습 모델은 바꾸지 않는다.

## 검증 범위

`test/strategy-preparation.cjs`는 작은 생성 국면의 회전·반사·색상 교환, 경계·막힌 연결·장목·현재와 미래의 3·3 금수, 중단 시 판 복원을 검사한다. `test/preparation-win.cjs`는 열린 3목·4목과 초기 연속 4목 승리가 없는 생성 국면에서 자동 분석이 준비 수를 실제 검증에 보내는지 검사한다. 모든 합법 응수를 별도 규칙과 증명 검사기로 재검증하고, 역공·시간 부족을 승리로 오판하지 않는지 확인한다.

원본 개인 대국은 로컬 재현에만 사용한다. 생성 검사와 한 대국의 개선은 전체 기력이나 모든 응수에 대한 무패 보장이 아니며, 새 신경망 모델의 채택 근거로 사용하지 않는다.

## 기보 따라두기

「기보 그대로 따라두기 (선택)」는 기본 해제다. v5.18.12에서 자동으로 켜졌던 상태도 최초 갱신 시 한 번 해제하며 등록 기보는 보존한다. 이후 사용자가 직접 켠 선택은 유지한다. 이전 형식의 JSON 백업도 이 기능을 자동으로 켜지 않는다. 일반 엔진 개선과 별개인 수동 기능이다.
