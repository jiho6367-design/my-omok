두 19수는 기존 필수 차단입니다. 기본 차단 추천을 승리 증명으로 바꾸거나 착수하지 않은 전략을 고정하지 않습니다. 상대 20수 뒤 첫 실제 조건부 추천을 두면 해당 19수 원전략을 저장하고, 상대의 다른 합법 응수에도 같은 증명의 전략을 이어갑니다. 자동 최대 15초와 기보 따라두기 해제 상태에서 기본 추천·반투명 선택·목록 선택에 연결됩니다. 과거 직접 설정 1초가 남아 있어도 자동 모드의 조회를 막지 않습니다.

상대 20 I8 뒤 새 첫 추천은 원증명의 **21 J6**입니다. 과거의 유효한 **21 J8** 증명과 기존 기보는 보존합니다. 옛 J8 전략을 실제로 둔 기록은 같은 증명을 유지하며, 선택 표식이 없는 J8 기보도 전체 경로가 일치하는 옛 전략으로 이어집니다. 현재 선택한 전략이 경로에서 벗어나면 다른 증명으로 조용히 갈아타지 않습니다.

등록 조건부 자료에 명시한 프로필을 40에서 42로 확장해 마지막 정책 착수 41수와 이후 즉시 승리 43수를 지원합니다. 기존 프로필 40 자료의 39수 정책·41수 즉시 승리 경계는 유지합니다. 원자료 S·사전분석 C 및 일반 시간제 검색의 40수 경계를 늘리지 않습니다. 조건부 자료의 상한도 512개 시작점·65,536개 노드·262,144개 응수 간선·8MiB 그대로입니다.

기존 261개 시작점과 1,892개 노드를 그대로 보존해 총 **263개 시작점·1,980개 노드·248,728개 응수 간선**을 사용합니다. 응수 간선 여유는 13,416개이며 기존 증거를 삭제하지 않았습니다. S 61,525개·C 32,602개와 채택 모델도 유지합니다. 두 원래 17수 전체 증명은 용량과 범위가 더 크므로 제품에는 이 두 정확한 19수 꼬리만 등록합니다.
