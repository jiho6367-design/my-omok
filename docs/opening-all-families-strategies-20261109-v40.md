# v5.18.40 유리한 21주형의 검증된 조건부 후속

v5.18.40은 기존 251개 조건부 전략을 보존하고, 실제 사용자 항성 분기의 늦은 21수 증명 한 개와 계월·우월·신월·협월의 정확한 시작점 여섯 개를 연결한다. 총 258개 전략이며, 지원하는 유리한 21주형 모두에 최소 한 개의 정확한 국면에서 검증한 승리 전략이 생겼다. **각 주형의 초기 9수나 주형 전체의 필승을 증명했다는 뜻은 아니다.** 불리·균형 5주형의 임시 제외는 유지한다.

자동 모드에서 기보 따라두기 선택 없이 현재 판과 일치하는 전략을 조회하고, 실제 기본 추천과 판 위 반투명 선택지로 제공한다. 첫 등록 전략을 실제로 선택하면 상대의 합법 응수에 맞춰 같은 원증명의 조건부 전략을 이어간다. 선택 기보 한 줄을 자동 재생하는 기능과 구분한다.

## 실제 항성 기보에서 추가한 시작점

항성은 I3이며 한성 D1·람월 I8과 다른 주형이다. 사용자의 백 선공 8수에서 직접 출발한다.

```text
1 H8   2 G7   3 F8   4 G8
5 G9   6 F10  7 H10  8 E7
9 I9  10 H7  11 I7  12 F9  13 I6
14 I10  15 H9  16 E10  17 D11  18 F7  19 D7  20 I8
```

이 정확한 부모판의 **21 J8 자체**에서 처음 얻은 전체 승리 증명을 등록했다. 합법 상대 22수 204곳과 필요한 모든 후속을 현재 규칙으로 검증했으며, 선택 진행은 같은 원증명을 유지해 전체 29수 종국까지 이어 두었다. 15 H9·13 I6·11 I7·9 I9 전체의 필승은 여전히 미증명이다. 같은 항성이라는 이유로 다른 대표 21수 분기를 대신 사용하지 않았다.

## 다른 네 주형의 정확한 여섯 시작점

자료가 있는 것만으로 등록하지 않았다. 우월의 별도 10 G7 분기는 기존 11 H11와 즉시승 처리로 이미 이어져 중복 추가하지 않았다. 계월의 별도 10 J10 진행에서 나온 선택 패배와 미증명 대안도 새 승리 전략에 넣지 않았다.

## 현재 규칙의 전체 증명과 측정값

규칙은 `15x15-exact5-both33-v1`이다. 두 색의 33 금수·정확한 5목 우선·합법 방어 전부·강제 위협과 VCF 종결을 독립 규칙으로 재생했다. 원자료의 일반 렌주 평가는 현재 규칙의 승리 근거로 대신 쓰지 않았다. 각 새 시작점에 선공 색 2가지와 D4 8변환을 적용했다.

기존 251개 대비 새 일곱 시작점의 독립 전체 증명은 **112건**이다. 먼저 항성 16건을 새로 검사했고, 이어 최종 258개 그래프에서 여섯 시작점 96건을 새로 재생했다. 최종 감사의 나머지 4,032건은 항성 16건을 포함해 시작점·노드·순서·ID·내용이 정확히 같은 기존 증거 재사용이다. 전체 근거는 96건 새 재생과 4,032건 재사용인 **4,128건**이며, 생산 과정에서 같은 그래프를 반복 검사한 횟수를 여기에 더하지 않는다.

새 원분석 일곱 개의 선언 예산은 모두 15,000ms이고, 아래 값은 보존한 원호출의 실제 측정값이다. 경과가 짧다고 예산을 1초나 3초 자료로 바꾸지 않았다.

과거 proof/depth/nodes/score를 현재 조회의 실시간 결과로 승격하지 않는다. 전략 조회는 현재 `proven` false, `proof` null, `depth/nodes/score/ms` 0을 유지하고 원증명 ID와 커서를 별도로 전달한다. 현재 판의 즉시승·필수 차단은 기존 전술 처리로 우선한다. 완료 비교만 있는 짧은 미증명 자료를 확정 전략으로 고정하지 않으며, 완전한 승리 증명이 있는 짧은 자료까지 일괄 제외하지 않는다.

## 실제 추천·선택·이어두기 검사 범위

격리한 v5.18.38 엔진과 기존 모델에 전체 258개 자료를 연결한 통합 API에서 **3,404회 조회, 시간제 검색 0회**를 확인했다. 새 부모의 양색·D4 112건, 원 백 선공의 모든 합법 다음 응수 1,457곳에서 pin 없는 추천과 실제 선택 기록을 JSON 저장·복원한 pin 추천을 각각 검사했다. 7개 부모 뒤 225점씩 1,575개를 실제 엔진과 독립 규칙으로 비교했고, 별도 D4 응수 표본 224건과 같은 원전략의 선택 종국 일곱 개도 확인했다. 이 API 검사는 전체 증명 나무 재생이나 모든 D4 형제 응수 검사가 아니다.

같은 격리 빌드의 실제 브라우저에서 새 부모 일곱 개의 첫 반투명 선택, 실제 착수, undo·목록 재착수·자연 pin 저장과 reload를 확인했다. 보드 35회와 목록 7회, 총 42회의 내 착수 클릭으로 일곱 선택 진행을 각각 27·29·29·23·13·23·항성 29수 종국까지 이어갔다. 기보 따라두기 off·자동 모드·수동 저장값 1,000ms·390px 화면에서 페이지 오류 0개였다. 상대 수는 검증할 선택 기보를 앱 착수 경로로 입력했다. 1,457판 전체를 브라우저에서 끝내거나 새 기력 비교를 한 검사가 아니다.

새 통합 검사는 명시한 소스·자료·모델·fixture·HTML을 받는 선택 실행이다. 원시 대국 보관소를 CI의 필수 입력으로 추가하지 않았다. 최종 버전의 공개 dist와 실제 사용 경로·개인 출력의 동일 바이트 실행, 기존 251/249/221 회귀, 게시 전 필수 검사와 Git 동기화는 최종 출시 기록으로 별도 확인한다. 위 격리 v38 검사를 최종 버전의 실행이나 전체 npm 검사 통과로 대신하지 않는다.

## 남은 범위와 반례

21주형 모두의 모든 상대 응수를 초반부터 증명한 것은 아니다. 특히 항성 9 I9와 H7 뒤 11 I7·13 I6·15 H9 전체의 필승은 미증명이며, 등록된 첫 전체 증명에 도달하기 전에는 자료 밖 응수의 실시간 분석이 필요하다. 지원하지 않는 국면이나 기존 조회 범위를 넘은 국면은 일반 분석으로 전환한다.

항성에서 상대 14 I5 뒤 15 J8과 상대 14 I10 뒤 15 J8은 서로 다른 판이다. 후자의 15 J8은 현재 규칙의 반례가 있어 이번 정적 자료에 넣지 않았고, 전자의 증명을 옮겨 쓰지 않았다. 계월의 별도 10 J10 진행에서 33 F13은 흑 34 C8 반격으로 패배가 증명된 고정 후보여서 제외했다. 별도 33 C8 대안도 선택 진행에서 62수 패배가 나왔지만 그 수 자체의 필패나 안전을 증명한 것은 아니다. 이 반례들을 9수나 주형 전체의 필패로 확대하지 않으며, 승리 자료에 섞지 않는다.
