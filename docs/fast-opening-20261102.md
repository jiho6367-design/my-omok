# 선공 초반 정석 즉시 추천 · 2026-11-02

v5.18.15는 선공의 첫 10수 범위에서 중앙 시작과 화월·포월의 정석 자료를 조회한다. 별도 체크나 인터넷 연결이 필요 없고, 등록된 현재 배치가 있으면 탐색 Worker를 시작하지 않고 추천한다. 선공의 착수는 전체 착수 번호 1·3·5·7·9수다. 10개 돌이 놓인 뒤에는 기존 분석으로 돌아간다.

## 자료와 포함 범위

원저자 Frank Arkbo의 [RenLib](https://www.renju.se/renlib/)은 D4.lib와 I7.lib를 Go-Moku와 Renju의 sure-win opening 자료로 소개한다. [Renju International Federation 주형 목록](https://www.renju.net/openings/)에서 D4는 Kagetsu(화월), I7은 Hogetsu(포월)에 해당한다. 원저자 배포 파일 `RenLib_v37.exe`는 실행하지 않고 ZIP 데이터로만 열었다.

- 배포 파일 SHA-256: `30712d1126ca873186f3ac3a1ff9cf0aec667b76d62cae9722323a556a77a80a`
- D4.lib SHA-256: `d12d1f416446c699c26df66be3c355cd8bcede29b0b6e46401751e5537b56962`
- I7.lib SHA-256: `63a2bdda875684c44faddbf3b93ed33ec8bd94d20754d1c1fbd590c1140a8f26`

공개 앱에는 초반의 사실 좌표 89개 항목과 출처 식별자만 넣었다. 중앙 시작은 별도 기본 항목이다. 원본 파일·주석·프로그램 소스는 배포하지 않는다. 원본에는 실패 변화도 있으므로 부정 표시가 있는 자기 수는 제외하고, 명시적인 좋은 수·A 변화 표시 또는 유일한 미배제 자기 수를 골랐다. 자기 추천이 불명확한 20개 분기는 넣지 않았다. 파일의 첫 번째 자식은 좌표 정렬 순서라서 추천 우선순위로 쓰지 않았다.

화월 예: H8 H9 I9 G10 G7 J10 I7 I10 F10. 포월 예: H8 I9 I7 H7 G9 F10 J6 K5 H6. 이는 예시 변화이며 상대의 다른 수에 그대로 이어 두는 고정 수순이 아니다. 등록된 다른 상대 응수에는 해당 분기를 조회하고, 없는 응수에는 기존 엔진을 사용한다. 은월 등 다른 주형은 이름만 확인한 것을 완성된 정석 자료처럼 추가하지 않았다.

## 동작과 판정

전체 배치·차례·선공 역할을 대조하며 회전·반사와 색 교환을 지원한다. 첫 수는 H8이어야 한다. 후공 차례, 맥락이 없는 판, 범위 밖, 등록되지 않은 배치, 불법 수, 충돌하는 추천은 기존 분석으로 넘긴다. 자료 조회 중에도 자기의 즉시 정확한 5목, 상대의 즉시 승리 차단과 검증된 반증을 우선한다. 후공 승리 기보의 「기보 그대로 따라두기」 체크와는 별개이며 체크 없이 활성화된다. 상대 차례 예측과 Worker 오류 시 상대 분석에는 이 선공 전용 자료를 사용하지 않는다.

화면은 「무적수 정석」과 「자료 조회」로 표시한다. 정석 조회에 탐색 완료 깊이·노드 수·강제승 증명을 붙이지 않는다. [RIF 규칙 9.1–9.3](https://www.renju.net/rifrules/)과 이 앱의 양측 3·3 금지, 양측 4·4 허용, 정확한 5목 규칙은 다르다. 따라서 원본의 승리 분류를 앱 규칙의 완전한 승리 증명으로 바꾸지 않는다. 현재 규칙에서 모든 수순의 합법성을 검사하고 실제 승패 증명은 기존 수읽기가 담당한다.

## 검사

생성 자료로 역할·흑백·8개 대칭, 정확한 배치 조회, 차례·10수 경계, 불법·중간 종료·충돌 거부, 위조 증명 제거와 즉시 승리·필수 방어 우선을 검사한다. 실제 브라우저에서 체크 해제 상태의 즉시 추천과 Worker 미생성, 수순 이탈·10수 이후 기존 분석 전환, 취소 동작, 화면 표시 및 1초 미만 전달을 확인한다. 개인 외형·기보 저장 키·기존 모델은 보존한다.
