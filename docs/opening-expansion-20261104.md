# 초반 정석 후속 확장 · 2026-11-04

v5.18.18은 선공의 정석 조회를 전체 10수에서 **21수째 착수까지** 확장한다. 내 11번째 착수에 해당하며, 모든 변화가 21수까지 등록됐다는 뜻은 아니다. 기보 따라두기 체크 없이 흑·백 어느 색으로 선공을 맡아도 적용한다. 상대가 등록된 변화에서 벗어나거나 전체 22수가 놓이면 기존 엔진이 현재 판을 분석한다.

## 실제로 늘어난 범위

기존 797개 사실 좌표를 보존하고 731개를 추가해 **1,528개**를 등록했다. 기본 3수의 화월·포월 우선 선택, 포월의 연결된 기본 5수, 유리한 변화가 있는 21주형과 제외한 5주형의 정책을 유지한다. 이번 후속 확장은 자동으로 들어가는 화월·포월에 집중한다. 나머지 주형에 새 후속을 넣었다는 뜻은 아니다.

| 추가 자료 | 항목 수 | 적용 범위 |
| --- | ---: | --- |
| 대만 배포 포월 라이브러리 | 421 | 새 7·9수 및 한 가지의 11~21수 |
| 대만 배포 한성·항성 라이브러리의 동일 배치 | 2 | 포월에서 같은 색 배치로 전환되는 7수 |
| 원저자 번호 도표 | 4 | 포월의 9·11·13·15수 |
| 기존 RenLib 화월 자료의 깊은 후속 | 87 | 11~21수 |
| 기존 RenLib 포월 자료의 깊은 후속 | 217 | 11~21수 |

포월 기준 방향 `H8 I9 I7 G9 J8` 뒤 상대의 합법 6수는 220개다. 등록된 7수 응수는 이전 **9개에서 46개**로 늘었다. 174개에는 여전히 정석 자료가 없으므로 일반 분석으로 전환한다. 새 46개 모두에 9수 후속이 있다는 뜻도 아니다. 예를 들어 기준 방향의 상대 I12는 이번 자료에서 7수까지만 연결된다.

사진 방향에서 이전에 미등록이었던 H6은 새 자료의 정확히 같은 배치로 연결된다.

`H8 G7 G9 I7 F8 H6 E7 D6 G8`

원자료는 상대의 4수와 6수를 다른 순서로 놓는다. 두 이력의 착수 합법성과 다음 자기 수 직전의 225칸 색 배치가 같은 것을 확인했다. 단순히 비슷해 보이는 판에 수순을 복사하지 않는다. 기존 F7 기보를 바꾸지는 않으므로, 새 기본 진행은 5수 직전에서 F8부터 확인한다.

## 조사한 원자료와 선별

[대만 렌주 자료실](https://587.renju.org.tw/program.htm)의 원배포 파일을 내려받아 자료로만 읽었다. 프로그램을 실행하거나 원본 라이브러리·도표·긴 주석을 재배포하지 않는다. 자료실 자체도 수순이 항상 최선이거나 오류가 없다는 보장을 하지 않는다. 포월 파일은 개별 분석자명이 확인되지 않았다. 한성·항성 파일은 분석자 俞满江, 정리자 逆刃을 구분한다.

- 한성·항성 `D1I3-2.rar` 안 라이브러리 SHA-256: `97f5b7c139fa6027a65f981619626800e4704f953a0f4c7554efeba62d4b6f33`

[励精连珠教室의 포월 설명](https://www.ljrenju.com/croom/i07/i07.htm)이 연결한 [동일 배치의 상세 도표](https://www.ljrenju.com/croom/i03/i03gd.htm#6i8j7k6)에서 번호와 좌표를 별도로 대조했다. 다음은 해당 도표의 15수까지 사실 좌표다.

`H8 I9 I7 G9 J8 I8 J7 K6 K7 H7 K9 H6 J10 L8 K8`

기존 [RenLib 배포 자료](https://www.renju.se/renlib/)에서는 실제 기존 추천을 9수까지 따라 도달한 가지의 11~21수를 선별했다. 304개 중 5개는 자기 수의 직접적인 긍정 표시가 있고, 299개는 부정·불확실한 자기 수를 제외한 뒤 남는 합법 후속이 유일하다는 문맥적 추론이다. 이 299개를 저자가 직접 필승이라고 명시한 수로 표시하지 않는다. 복수의 미평가 후보는 임의로 고르지 않는다.

새 라이브러리에서는 정확한 색 배치와 회전·반사를 대조하고 기존 추천을 보존했다. 새 동일 배치 조사에서 자기 9수가 갈리는 11개 국면은 추가하지 않았다. 기존 자료의 232개 충돌 배치 키도 일반 분석으로 넘기는 정책을 유지한다.

## 수읽기와 승리 표시

[Allis 등의 오목 수읽기 논문](https://cdn.aaai.org/Symposia/Fall/1993/FS-93-02/FS93-02-001.pdf)은 수순 데이터베이스와 위협 탐색을 결합한 사례를 설명한다. 이번 작업에서는 자료 조회와 실제 판 분석을 구분하는 기준으로 참고했다. 논문의 새 탐색 알고리즘을 이번 버전에 이식했다거나 그 논문의 해결 결과가 이 앱에도 성립한다고 주장하지 않는다.

원자료의 표준 렌주와 앱의 양측 3·3 금지·양측 4·4 허용·정확한 5목 규칙은 다르다. 모든 추가 경로의 현재 규칙 합법성은 검사하지만, 정석 조회 자체는 승리 증명이 아니다. 조회 결과는 깊이 0·증명 미완료로 표시하며, 자기 즉시 승리·필수 차단·확인된 반증은 계속 우선한다. 이미 정확한 5목으로 끝난 판은 더 긴 조회 범위에서도 정석을 반환하지 않는다. 장목을 정확한 5목으로 오인하지 않는다.

## 검증

`test/opening-expansion.cjs`는 공개한 좌표만 사용한다. 새 731개를 두 색·8개 대칭의 11,696개 경우에서 검사하고, 각 항목에 이르기 전 자기 추천도 실제로 이어지는지 확인한다. 원자료와 전환된 수순의 색 배치를 독립 규칙 검사기로 대조한다. 220개 상대 6수를 전수 조회해 등록 범위 46개를 확인하며, 미등록 응수의 일반 분석 전환을 유지한다.

실제 브라우저 검사는 체크 해제 상태에서 추천 수를 `commit()`으로 놓고 상대 응수를 적용한다. 사진의 H6 연결, 도표의 15수, 자료의 21수, 화월의 11수를 두 색에서 확인한다. 13·19·21수의 필수 차단 우선도 유지한다. 생성된 시험 수순으로 11~21수 조회, 전체 22수 이후 전환, 종료된 5목 거절과 비종료 장목도 별도로 검사한다. 로컬 전체 라이브러리나 개인 기보는 CI의 필수 입력이 아니다.
