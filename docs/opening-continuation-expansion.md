# 검증된 무적수 후속의 전 모드 조회 · v5.18.59

이미 완전 검증된 조건부 전략은 실제 앱의 10초·15초·25초 모드 모두에서 상대 응수에 맞춰 이어 둡니다. 과거 증명에 선언된 분석 예산보다 긴 모드를 골랐다는 이유로 다시 탐색하던 경로를 개선했습니다. 일반 사전분석의 비교 결과나 자료상의 정석 평가는 이 예외에 포함하지 않습니다.

## 이번에 추가한 완주 수순

기존 자료가 끝난 뒤 즉시승·필수 차단도 없어 일반 분석으로 넘어가던 늦은 분기 15개에서 새 승리 증명을 만들었습니다.

| 주형 | 추가한 정확한 분기 |
| --- | ---: |
| 잔월 | 1 |
| 신월 | 2 |
| 은월 | 8 |
| 협월 | 2 |
| 운월 | 1 |
| 람월 | 1 |

각 분기의 35·37·39수부터 상대의 모든 합법 응수와 다음 방어를 검사했습니다. 해당 전략을 따르면 전체 39·41·43수 이내에 정확한 5목으로 승리합니다. 예를 들어 잔월의 특정 39수 H13 이후 상대가 40수 K13으로 막은 뒤에도 검증된 공격을 이어갑니다. 같은 주형의 다른 돌 배치 전체를 검증했다는 뜻은 아닙니다.

포월은 기존에 완주가 확인된 19수 I7 전략을 정확한 16돌 부모판의 **17수 H6**까지 앞당겨 연결했습니다. 상대 18수의 합법 응수 208개 전부를 포함하며 최장 종국은 전체 45수입니다. 이는 공개된 19수 증명에 새로 검증한 앞부분을 합성한 증명입니다. 과거 엔진이 17수의 승리를 이미 증명했던 것으로 표시하지 않습니다.

새 증명은 원본과 실행용 압축 전략을 각각 두 색·8가지 회전/반사에서 재생하고, 독립 증명 검사기와 별도의 기하학 규칙 검사기로 검증합니다. 규칙은 양쪽 3×3 금지, 4×4 허용, 정확한 5목 우선, 장목 비승리입니다.

## 보존과 표시

기존 267개 전략의 좌표·순서·원증명 식별자와 노드 값은 보존합니다. 기존 증명의 전 모드 재사용은 새 증명을 발견하거나 실시간 탐색한 것으로 표시하지 않습니다. 현재 조회의 깊이·노드·점수·증명은 과거 탐색 수치와 구분합니다. 기존 전략에서 필요한 즉시 차단도 실제 판·순서·증명과 일치할 때만 같은 전략의 맥락을 유지합니다.

새로 전 응수를 검증한 등록 국면은 **엔진 검증 무적수**, 기존 검증 전략은 **검증 수순 이어두기**로 표시합니다. 원래 무적수·정석과 별도 동등5수 선택은 유지합니다. 신경망 모델과 일반 수읽기 알고리즘은 변경하지 않습니다.

모든 주형의 모든 상대 응수가 해결된 상태는 아닙니다. 미검증 분기는 일반 분석으로 넘기며, 분석 시간이 짧거나 자료가 있다는 이유로 필승으로 승격하지 않습니다. 실제 앱에서 검증 전략을 재사용하는 정책과 기본 엔진 API의 기존 예산 정책은 구분됩니다.
