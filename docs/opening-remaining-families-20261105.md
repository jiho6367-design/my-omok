새 11수는 주형별 최대 400개, 그 뒤 13~39수는 주형별·차례별 최대 40개의 연결된 가지를 골랐다. 등록된 부모별로 고르게 배분하고 가까운 응수를 먼저 검토하는 것은 자료 범위를 고르는 기준이며 수의 강도나 필승 순위를 뜻하지 않는다. 원본 라이브러리·주석·영상과 개인 자료는 배포하지 않는다.

## 조회와 검증

원자료·즉시 승리·필수 차단·확인된 반증을 우선한다. 사전분석은 정확히 일치하는 저장 국면에서만 조회하며, 자료 밖 국면은 기존 엔진이 분석한다. 명시적인 심층 분석이나 저장 예산보다 긴 수동 분석은 새로 계산한다. 저장된 점수·깊이·노드를 현재 탐색의 성과로 옮기거나 현재 조회를 강제승 판정으로 표시하지 않는다.

사전분석 자료가 커져도 첫 조회가 지연되지 않도록 현재 판의 전체 돌 배치·차례와 일치하는 항목을 먼저 고른 뒤 기존의 전체 경로·증거·합법성 검사를 적용한다. 전체 자료를 검사하는 기존 API도 유지한다. 중복 식별자가 있으면 전체 검사로 돌아가 먼저 유효한 항목을 처리하는 규칙을 보존하고, 한 판에 골라 놓은 자료가 다른 판을 대신 처리하지 않도록 조회 범위를 제한한다.

원자료의 여러 대안 때문에 기본 추천이 정해지지 않아 엔진 사전분석 수를 쓰는 경우에는 그 추천도 반투명 선택에 함께 표시한다. 원자료 대안을 유지하고 같은 좌표의 주형 이름은 합치며, 원자료 기본 추천이 정해진 경우에는 기존 우선순위를 따른다.

공개 엔진의 자동 모드·기보 체크 해제 상태에서 고정 대상 9,282국면 모두 합법 대응을 조회했다. 새 원자료는 양색·8대칭 139,648조회와 부모 연결 39,559개, 전체 저장 분석 응수는 양색·8대칭 243,856조회를 확인했다.

브라우저에서는 새 엔진 응수 656국면과 새 원자료 224국면을 확인했다. 새 엔진 응수 표시 최대 135ms, 새 원자료 추천 최대 248ms였다. 반투명 선택의 실제 클릭·무르기, 기보 옵션 독립성, 양색·대칭·모바일·명시적 심층 Worker 전환과 기존 수순 회귀 검사를 통과했다. 계산 원결과·승리 수순·원본 라이브러리·배포 데이터 보존은 별도로 대조했다.

기존 5,217개 사전분석 항목과 이전 분석 정보·확장 기록, 기존 40,855개 원자료는 순서·좌표·증거 해시를 보존한다. 사전분석 저장 상한은 16,384개이며 등록은 유리한 21주형으로 제한한다. 공개 dist/index.html과 이 PC의 실제 outputs/omok.html은 같은 공개 엔진으로 빌드한다. 개인 외형·저장 키·기보·기존 모델과 별도 미완성 실험은 유지한다.
