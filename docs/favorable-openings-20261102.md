# 상대 2수에 따른 유리한 주형 선택 · 2026-11-02

v5.18.16은 전체 26주형을 검토하고, 유리한 변화가 확인된 21주형의 정석 자료를 사용한다. 선공이 흑돌인지 백돌인지와 관계없이 적용하며 「기보 그대로 따라두기」 체크가 필요 없다.

## 우리 3수의 선택

중앙 H8로 시작한 뒤 상대의 2수가 가로·세로로 인접하면 화월 D4, 대각선으로 인접하면 포월 I7을 우선한다. 기준 방향에서는 각각 `H8 H9 I9`, `H8 I9 I7`이며 회전·반사된 여덟 인접 방향을 처리한다. 두 기본 선택은 [RenLib 배포 자료](https://www.renju.se/renlib/)가 강한 선공 주형으로 소개하는 수순이다. 상대가 멀리 두어 26주형의 정의에 맞지 않으면 기존 엔진이 현재 판을 분석한다. 이 선택은 자료에 따른 우선순위이며 현재 앱 규칙에서 모든 3수를 비교한 최적성 증명은 아니다.

다른 주형의 후속 수순을 추가하면서 공통된 2돌 배치에 서로 다른 3수를 한꺼번에 등록하지 않는다. 새 자료의 각 항목은 문맥 전체를 합법성 검사하되, 해당 자료가 실제로 추천하는 5·7·9수만 조회에 등록한다. 따라서 자료 확장이 기본 3수 선택을 충돌시키지 않는다.

## 유리한 주형의 허용 기준

[사용자가 지정한 주형 목록](https://renjulike.tistory.com/530)을 [RIF의 26주형 명칭](https://www.renju.net/openings/)과 대조했다. [Yuriy Tarannikov의 이론 정리](https://www.renju.net/forum/thread/305/)에는 21주형에서 선공에게 유리한 5수 선택이 명시되어 있다. 이 자료를 토대로 한 허용 정책이며, 모든 응수에서 선공이 이긴다는 분류로 확대하지 않는다. 원자료의 개정일은 2009-08-29이고, 야마구치의 복수 5수 제안 개수와 이 앱의 자유 착수는 구분한다.

- 균형 평가로 제외: 소성 D3, 장성 I1, 간접 유성 I5.
- 후공 유리 평가로 제외: 직접 유성 D13, 혜성 I13. [RIF 직접주형 자료](https://old.renju.net/study/d111213.php)와 [간접주형 자료](https://old.renju.net/study/i10_13.php)에서도 두 13번 주형의 후공 우세를 설명한다.

위 다섯 주형은 정석 추천 항목에 넣지 않는다. 별도로 시도한 불리한 주형의 후보 비교도 공개 정석에 넣지 않는다. 사용자가 다른 수로 판을 만들면 현재 배치를 분석하는 기존 엔진이 계속 동작한다.

## 수순 자료와 범위

RenLib에 동봉된 `Allrenjuopenings.lib`와 기존 D4·I7 자료에서 초반 사실 좌표를 선별했다. 전체 라이브러리는 RenLib 배포자 Frank Arkbo와 분석 기여자 `lanxingzhihai`를 구분해 출처를 기록한다. 원본·프로그램·주석은 배포하지 않는다. 전체 라이브러리 SHA-256은 `6605a147c27fdea4fb2e61e43312718f85be4f24096d4f5ee48d139f52f1eac8`이다. 파서는 실제 39,884개 착수 노드를 확인했으며, 홈페이지의 39,886 표기와의 차이를 보존한다.

등록된 항목은 기존 3수 기본 선택 2개와 후속 수순 774개, 총 776개다. 출처의 실패·불확실한 자기 수는 제외했고, 명확하지 않은 분기는 기존 분석으로 넘긴다. 대칭을 포함한 232개 배치 키에서 자료의 추천이 충돌하므로 삽입 순서로 고르지 않고 일반 분석으로 넘긴다. 등록되지 않은 상대 응수와 전체 10수 이후도 기존 엔진을 사용한다. 자료가 끝난 주형은 10수 전이라도 일반 분석으로 전환한다.

[RIF 규칙](https://www.renju.net/rifrules/)과 앱의 양측 3·3 금지·양측 4·4 허용·정확한 5목 규칙은 다르다. 현재 규칙의 합법성은 검사하지만 원자료의 유불리·승리 분류를 강제승 증명으로 이전하지 않는다. 자기의 즉시 승리·필수 차단·검증된 반증은 정석보다 우선한다.

## 검증

현재 규칙의 독립 규칙 검사기로 776개 수순을 검사한다. 허용된 21주형의 실제 5수 조회를 흑백·8개 대칭의 336개 경우에서 확인한다. 상대의 인접한 2수에 따른 화월·포월 선택과 새 후속 자료가 그 선택을 방해하지 않는지도 검사한다. 실제 브라우저에서는 별도 체크·Worker 없이 추천하는지, 등록되지 않은 응수·10수 이후에 기존 분석을 시작하는지와 1초 미만 전달을 확인한다. 정석 조회는 강제승 표시나 완료된 탐색 깊이를 만들지 않는다.
