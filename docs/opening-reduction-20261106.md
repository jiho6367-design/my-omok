# v5.18.30 · 큰 사각형 2수의 주형 환원

중앙 H8에 선공 첫 돌을 놓은 뒤, 상대 2수가 작은 3×3 사각형 밖의 5×5 테두리 16칸에 오면 유리한 주형으로 환원되는 3수를 바로 조회한다. 선공 역할은 돌 색과 별개이며, 자동 최대 15초 모드에서 기보 따라두기 체크 없이 적용한다. 가능한 3수는 반투명 돌과 `포월 환원` 같은 이름으로 선택할 수 있다.

## 적용 범위

16곳의 상대 2수에 총64개의 서로 다른 3수 선택지가 있다. 회전·반사를 포함한 원자료 배치 연결은72개다. 실제 세 돌을 전부 보존하고, 내 첫 돌과 내 3수의 역할 순서만 바꿔 중심을 옮겨 같은 색 배치가 되는지를 검사한다. 상대 돌을 지우거나 없는 돌을 가정하지 않는다.

| 상대 2수의 방향 | 위치 수 | 위치별 3수 선택지 | 환원 주형 | 기본 참고 주형 |
| --- | ---: | ---: | --- | --- |
| 가로·세로 두 칸 | 4 | 5 | 포월·잔월·송월 | 포월 |
| 한 칸·두 칸 비껴선 위치 | 8 | 4 | 수월·금성·구월·은월 | 수월 |
| 대각 두 칸 | 4 | 3 | 신월·사월 | 신월 |

예를 들어 상대 H10 뒤에는 G9·I9가 포월, H9가 송월, G10·I10이 잔월로 환원된다. 바깥 테두리를 넘어선 다른 2수는 이번 환원 정책의 대상에 포함하지 않는다.

기본 추천은 포월·수월·신월을 우선하는 명시적인 참고 정책이다. 선택지 사이의 최강수 비교나 환원된 유한 보드의 필승 증명을 뜻하지 않는다. [원저자 수월 자료](https://www.ljrenju.com/croom/i04/i04.htm)와 [신월 자료](https://www.ljrenju.com/croom/d10/d10.htm)를 참고했으며, 원자료의 일반 렌주 평가와 앱의 정확한5목·양쪽33금지 규칙을 구분한다.

## 3수 이후 연결

실제 기보가 중앙 첫 돌·바깥 2수·해당 환원 3수로 시작하고, 전체 착수와 현재 판이 정확히 일치할 때만 환원 원자료의 후속을 조회한다. 원본 전체 수순과 옮긴 전체 수순이 모두 합법이고 판 안에 남는지 확인하며, 추천 직전에도 실제 판에서 다시 검사한다. 뒤의 수가 판 밖으로 나가거나 금수가 되는 수순을 앞부분만 잘라서 사용하지 않는다.

불러오기·되돌리기는 실제 기보를 다시 전달한다. PASS가 섞이거나 기보가 없고 불일치하면 3수 이후의 환원 후속을 사용하지 않는다. 일반 원자료의 기존 우선순위는 유지한다. 상대 예상 응수의 사전 계산이 있더라도, 실제 착수 뒤 환원 원자료가 확인되면 현재 실제 기보에 맞는 원자료를 먼저 보여준다.

기존 사전분석 대응의 좌표·점수·깊이·승리 증명을 옮겨 쓰지 않는다. 등록된 환원 원자료 후속이 없으면 기존 일반 엔진 분석으로 이어진다. 기존 원자료61,441개·후속 사전분석31,779개·별도 초기174개 응수와 채택 모델의 원본은 유지했다.

## 근거와 검증

[원저자 환원 예시](https://renjulike.tistory.com/802)는 선공 돌의 착수 순서를 바꿔 같은 판을 다른 주형으로 해석한다. 이것이 이번16칸 전체의 필승 정리라는 뜻은 아니다. [원저자 잔월 자료](https://www.ljrenju.com/croom/d05/d05.htm)는 가장자리 거리에 따라 평가가 달라지는 예도 보여준다.

이 앱에서도 원본 후보는 합법이지만 중심을 옮긴 후보는33금지가 되는 별도 반례로, 실제 판의 재검사를 확인했다. 환원 결과는 원자료 참고이며 현재 탐색의 승리 증명으로 표시하지 않는다. 점수·깊이·노드와 현재 비교 완료를 만들어 넣지 않는다.

관련 단위 검사6개를 통과했다. 새 환원 검사는 양쪽 돌 색과8방향의 256개 기하 국면, 실제 원자료5·7수 288개 국면과 기보·경계 검사368개를 포함한다. 기존 직접·간접3수 기본 추천과 원자료 우선순위도 확인했다. 별도 검토자는 원본 자료와 환원 배치를 다시 계산하고, 실제 코드의 기보·캐시·예측 계산 경로를 검증했다.

원자료 후보가 서로 모호한 경우에도 새 환원 추천이 선택 목록에 포함되는지 검사한다. 이전 구현에서 추천110이 선택지[0,1]에 빠지는 별도 생성 사례를 실패로 재현했고, 수정본은 [0,1,110]을 반환한다. 원자료의 유효한 기본 추천이 있으면 기존 우선순위를 유지한다.

공개 빌드 화면 검사14개를 통과했다. 새 기능은 256개3수 국면과 36개 후속 국면에서 반투명 돌·선택 목록, 클릭·되돌리기·불러오기, 기보 체크 해제와 모바일390px를 확인했다. 실제 착수 뒤 현재 환원 정석이 미리 계산한 일반 응수보다 우선하는 경우도 검사했다. 새 기능의 추천 표시 시간은 이 검사에서 최대132ms였으며 화면 오류가 없었다.

공개 실행본은 흑백 돌의 `dist/index.html`, 이 PC의 실제 `outputs/omok.html`은 기존 개인 외형과 저장 키를 보존한 빌드다. 기존 개인 기보·모델·이미지와 별도 실험 작업을 유지한다.
